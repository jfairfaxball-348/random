# Catalogue Taxonomy Scaffold

This file defines tag families only. It intentionally contains no substantive Phase-1 findings.

Future tags should cover, as the research itself justifies:
- mathematical subfield;
- randomness notion/definition;
- characterization technique;
- effective test or betting/prediction framework;
- complexity/information framework;
- measure/category framework;
- implication/equivalence/separation relation;
- computability strength/oracle dependence;
- finite versus infinite object;
- application/interface area;
- historical/priority status;
- open/resolved/status-uncertain question;
- source access/evidence level.

Phase 1 should refine this taxonomy rather than assuming these headings are complete.
