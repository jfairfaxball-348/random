# Phase-1 Catalogue Architecture

This directory is currently an empty schema, not a literature review.

External papers are catalogued, not automatically stored. The future Phase-1 agent should populate structured records with stable IDs and create derived indexes for definitions, theorems, relations, questions, authors and search vocabulary.

Core files:
- `catalogue.json` — machine-readable top-level index;
- `schema/source-entry.schema.json` — source metadata contract;
- `taxonomy.md` — architecture for topic tags, initially unpopulated.

No source in the catalogue currently implies endorsement, completeness or novelty status because there are presently no source entries.
