## A166 — A total exact-rational martingale wins on the SAME B source

S165 fixes an arbitrary total computable p:2^{<ω}→{none,0,1} and builds a globally fair total additive-two G_p∈F3. R(τ) partitions ALL length-(|τ|+2) source words into four tagged cells, ACTIVE phase 0 A3/B1, ACTIVE phase 1 A2/B2 or SAFE P2/S2.

**Theorem A166.1 (internal, uniform in p).** There is ONE total ordinary nonnegative exact rational computable SOURCE martingale e_B with e_B(empty)=1 that succeeds on the unique B-sector inverse x_B of EVERY output y for which p predicts infinitely often, ALL predictions correct.

**Explicit algorithm on EVERY source string.** Begin with e_B(s)=1 for |s|≤2. For each source parent s of length n≥2, find by a finite row search the UNIQUE τ of length n−2 with s∈R(τ). (The rows partition all source words; thus this terminates on EVERY s, not merely on inverse streams.) If R(τ) is ACTIVE phase 1, p(τ) is 0 or 1, and s equals the FIRST B-labelled cell b0 in its B2 slots, set
    e_B(s0)=2e_B(s),  e_B(s1)=0.
Otherwise set
    e_B(s0)=e_B(s1)=e_B(s).
The value at each finite string is recursively computable, nonnegative and an exact power-of-two rational (possibly zero). On ALL parents, including SAFE, mistaken predictions, nonexistent challenges and losing cells, e_B(s0)+e_B(s1)=2e_B(s); hence this is a legal fair-source martingale, not a post-selected strategy.

**Proof of success.** On a correct predicted transition from phase 0 the B sector becomes two tagged B cells in phase 1; on the next correct predicted phase1 transition it becomes one B cell in phase0. FREE transitions leave phase unchanged and never remove the sector. With infinitely many correct predictions, infinitely many occur at ACTIVE phase1. At each such stage the exact S165 winning phase1 row has B cells ONLY [B:b0 0]. The other child of b0 and BOTH children of b1 go to the losing SAFE row. The actual full x_B can never take those losing edges since G_p(x_B)=y and y has no incorrect prediction. Thus its current parent is b0, its next source bit is 0, and the ONE e_B doubles. No bet loses on x_B, and infinitely many successful doubles force unbounded capital. By definition x_B∉CR, so x_B∉R2: identity is a globally fair total singleton-fibre map already in F2. QED (same-agent proof).

## B166 — Effective partial selectors, and why finance does not automatically follow

For every y∈E_p, S165's global inverse theorem gives one complete A stream and one complete B stream. **Lemma B166.1:** A(y),B(y) are PARTIAL y-computable on E_p. Given source precision ℓ, successively enumerate the finite A-labelled, respectively B-labelled, source cells in R(y↾m). Search for the first m≥ℓ at which their length-ℓ prefixes ALL coincide; output that prefix. Nonemptiness is guaranteed on E_p.
