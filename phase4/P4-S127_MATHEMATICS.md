## B127 — EXACT four-cell, three-inverse laboratory

For G with first m output bits decided by first m+c source bits and fair, every output cylinder [τ] of length m contains EXACTLY 2^c compatible source words of length m+c: its λ-measure is 2^{-m}, and each aligned source cell has mass 2^{-(m+c)}. This holds for m=0 and every off-path τ. Any fibre G^{-1}(y) has ≤2^c actual infinite points: more distinct inverses would eventually require >2^c distinct compatible aligned source prefixes. The cap bound needs both fairness and the uniform use; without fairness only the exact count fails.

For k≥2, define the complete prefix code P_k = {0,10,110,...,1^{k-2}0,1^{k-1}} (k words; code lengths 1,...,k-1,k-1). Define T_k(pu)=u for the **unique** p∈P_k. Kraft sum ∑_{p∈P_k}2^{-|p|}=1. Thus λ(T_k^{-1}[τ])=∑_p 2^{-|p|}λ([τ])=2^{-|τ|} for every τ; T_k is total, computable, onto, has exactly k full infinite inverses {py:p∈P_k} at EVERY y, and absolute additive use at most k−1. No stray exceptional or boundary inverses exist because P_k partitions X. At k=3, P_3={0,10,11}, c=2, and for EVERY m and τ exactly four length-(m+2) source cells occur: TWO in the 0 sheet and ONE each in the 10/11 sheets. For m=0, the four cells are 00,01,10,11. Each pair of finite 0-sheet cells eventually resolves to ONE actual inverse, so a perpetual spare CELL is not a fourth actual path. There is no circulation among the true cones. The model is globally fair but conserves CR and every R_j, so it is NOT the requested destroyer.

**General three-cone occupancy lemma (internal):** Suppose c=2 and y has exactly three infinite inverses x_1,x_2,x_3. Choose disjoint finite source cylinders B_i containing precisely x_i. For all sufficiently large m, all four compatible (m+2)-cells belong to ∪B_i: otherwise a subsequence of compatible cells outside that clopen union has an infinite nested branch yielding a forbidden fourth inverse by compactness. Each B_i contains at least one, hence the cell multiplicities are necessarily a permutation of (2,1,1). This is an eventual existence statement, NOT an effective modulus. For general c and r actual inverses, the 2^c-cell occupancy vector eventually has r positive integer entries summing 2^c; there are exactly 2^c−r surplus cells relative to one-per-actual-cone.

**Local rotation feasibility ≠ global cap.** At a parent with counts A:2,B:1,C:1, let the two source children of A_1 split 0/1, those of A_2 both choose output child 1, those of B both choose child 0, and those of C split 0/1. Output child 0 has (A,B,C)=(1,2,1), child 1 has (3,0,1): four slots EACH and exact source-child accounting, so a single 2+1+1 rotation is combinatorially possible. But the sibling has potentially four full inverses (three A plus one C). Without an infinite continuation tree that removes at least one there, this row is NOT a legal F3 certificate. Alternating A→B→C or A→C→B clocks repeats the unproved sibling-boundary obligation. No global, fully verified circulating-ghost F3 example, triple-CR/nonCR witness or rational output destructor was produced.

**Volatility restriction (extends S117's proof to any c,r):** For clopen source B resolved at depth m+c define q_B(τ)=2^{|τ|}λ(B∩G^{-1}[τ]). Its entries are multiples of 2^{-c}; 0≤q≤1; q(τ0)+q(τ1)=2q(τ). Let δ(τ)=(q(τ0)−q(τ1))/2, v(τ)=q(τ)(1−q(τ)). Then V_B(τ)=v(τ)+∑_{ρ≺τ}δ(ρ)^2 is ONE total computable nonnegative rational OUTPUT martingale, because average child v = parent v −δ². Each grid change along an output branch adds at least 4^{-c} to V_B. Thus at CR outputs each fixed finite clopen source-cone occupancy eventually stabilizes; a triple spare cannot circulate forever there. On a nonCR output such circulation is NOT ruled out, exactly where a destructor would need it. For B_i isolating three actual inverses, ∑_i V_{B_i} is a concrete ordinary rational winner if the spare rotates infinitely. This is an OUTPUT witness, not a source CR contradiction; it neither constructs a circulating map nor proves R2=R3.

## C127 — Multiplicative fibres, iteration and sharpness

Let F∈F_b and H∈F_a. H∘F is total computable and fair by pushforward measures; for every y, (H∘F)^{-1}{y}=∪_{u∈H^{-1}{y}}F^{-1}{u}, a disjoint union with at most a·b actual elements. Hence H∘F∈F_{ab}. The bound is SHARP for all positive a,b: the just-proved T_b and T_a are everywhere exactly b and a inverse, so T_a∘T_b has exactly ab actual inverses over every y. In particular T_2∘T_2 has four full inverses and lies in F4 but not F2; cap is not stable under composition. This proves sharpness of cardinality bounds, not a destructive example.

**Cross-level theorem (INTERNAL):** F_b(R_{ab})⊆R_a. For x∈R_ab and F∈F_b, for EVERY H∈F_a the composite H∘F∈F_ab, so H(F(x))∈CR. Identity is in F_a, giving F(x)∈CR. Thus F(x)∈R_a. Special case F2(R4)⊆R2.

If F2(R2)⊄R2, select x∈R2, F∈F2 with F(x)∉R2; by definition some H∈F2 has H(F(x))∉CR, witnessed by a total rational output martingale. The composite is F4, so x∈R2\R4. ## E127 — Safe general-k code/homeomorphism theorem with coherent rational certificates

Let P be ANY finite complete binary prefix code of size k, and for each p∈P choose a total computable fair **homeomorphism** H_p:X→X with effective inverse (no uniform additive use required). Define G(pu)=H_p(u). For every τ, λ(G^{-1}[τ])=∑_{p∈P}2^{-|p|}λ(H_p^{-1}[τ])=2^{-|τ|}. Exact full fibre G^{-1}{y}={pH_p^{-1}(y):p∈P}, of size k for ALL y; no exceptional paths since P is complete. This is an F_k theorem with arbitrary nonlinear chart clocks and no fixed c. It preserves EVERY R_j, not merely CR:

If pu∈R_j then u∈R_j: for arbitrary K∈F_j set L(x)= (x↾|p|) concatenated with K(x after |p|). L is globally fair, total computable and cap j (output tag gives unique first |p| source bits); L(pu)=pK(u). A nonCR K(u) would make pK(u) nonCR, contradicting pu∈R_j. Next H_p(u)∈R_j because K∘H_p ∈F_j for every K∈F_j (H_p is a fair bijection). Thus G(R_j)⊆R_j for every j, including j=1. Finite-prefix CR reflection shows **for nonCR y none of the k preimages pH_p^{-1}(y) can be CR**. Consequently adding a safe identity/homeomorphism sheet to an unsafe branch cannot yield an ALL-k-CR-preimage bad-output witness. (It can produce a bad output with at most some CR preimages; do not mislabel.)

For H_p=id, there is even a DIRECT **single ordinary rational source martingale compiler**: given nonnegative total rational d winning on output y and d(ε)=1, put
M(s)=∑_{p≼s}d(s after p)+∑_{s≺p}2^{|s|−|p|}.
Prefix-freeness makes the cases exclusive per p; the exact identity M(s0)+M(s1)=2M(s) follows by checking whether the source cursor is before or after its uniquely selected codeword. M(ε)=∑_p2^{-|p|}=1; for s=pv, M(s)=d(v), so it wins at py whenever d wins at y. An arbitrary nonnegative d with root not 1 is handled by scaling or adding the constant martingale. No effective measure on a ramification closed set and no inverse-selector is used. For general distinct H_p, the R_j proof uses known fair-homeomorphism conservation rather than claiming this same simple expression compiles arbitrary unbounded-use charts.

This class includes exact three-inverse c2 T3, ALL arbitrary finite k, heterogeneous charts and arbitrarily unbounded use. The fact that a chart family is safe does NOT show every F_k is charted. It is a genuine restricted general-k theorem, not a priority/newness claim.

**E score:** PROVED INTERNALLY global all-fibre/pricing conservation and explicit rational finite-code compiler, with stated existing E-ISO dependency for chart invariance. OPEN extension to nonhomeomorphic boundary-folding observers.
