## A146.1 — Sharp impossibility for a price-blind universal c.e.-open escrow

**Proposition (internally verified sharp barrier, not new hierarchy theorem).** There is NO algorithm which, for EVERY uniformly c.e.-open family (U_k) with λ(U_k)≤2^(-4k), constructs a total nonnegative rational computable martingale succeeding on EVERY sequence belonging to infinitely many U_k. This remains false if the algorithm knows all numerical upper bounds 2^(-4k), has arbitrarily many finite-stage approximants, and may spread capital through infinitely many accounts.

**Proof.** Use the standard strictness CR⊋MLR: fix z that is computably random but not Martin-Löf random. Let (T_n) be a universal Martin-Löf test with λ(T_n)≤2^(-n), containing z in every T_n; put U_k=T_(4k), uniformly c.e. open with the advertised small upper bounds. Since z∈U_k for ALL k, a universal extractor would return a total rational computable martingale succeeding on z, contradicting z∈CR. The argument is semantic and uniform, not a finite sampling counterexample. No assertion about the individual prices λ(T_n) follows from this alone.

**More explicit stage-late obstruction (already implicit in S143/S145, recorded for the scheme).** For every total computable stage-choice function t(k), let U_(k,t(k)) be a clopen finite union from the uniform enumeration. Their rational exact measures are computable and ≤2^(-4k), so S145 A145.1 gives a total rational martingale if z lies in infinitely many. Consequently z∉U_(k,t(k)) for ALL sufficiently large k even though z∈U_k for every k. A strategy whose only guarantee is “the event eventually appears somewhere in the enumeration” has no computable capture schedule along this z. This is NOT the stronger false claim that a fixed test component never contains z at any finite stage, and it does not establish how late a particular noncomputable first-entry function grows without specifying the enumeration.

**Precise implication.** Converting a general left-c.e. event price to a computable bet using only the budget bound would prove CR=MLR, a false assertion. In particular any all-G general stopping rescue must exploit additional map/fibre information; it cannot apply verbatim to every uniform ML test. The S011 globally fair F2 CR destroyer independently refutes an indiscriminate all-fair-map preservation proof.

## B146.1 — Exhaustive labelled four-cell allocation and two-bit capacity

Let y have EXACTLY TWO actual inverse points x_A∈A and x_B∈B isolated by disjoint clopen cones. Beyond a non-effective but finite stabilization point, every compatible source cell lies in A∪B and the A count q=1,2,3, the B count 4−q. Each of four source parent cells has two children; global fairness requires exactly four of the eight children allocated to each output bit. Fix one output child as the true target, with A count t∈{1,2,3}. Then sibling A count is 2q−t and sibling B count 8−2q−(4−t)=4−2q+t. Seven target transitions: (q,t)=(1,1),(1,2),(2,1),(2,2),(2,3),(3,2),(3,3). Importantly sibling A count may be 0 or 4; that sibling is NOT an additional point of the fixed y fibre.

**Exact labelled count.** Each row choice is a four-element subset of the eight individually labelled source children. For given q,t there are C(2q,t) C(8−2q,4−t) assignments, namely respectively 40,15,16,36,16,15,40 in the order above: TOTAL 178 fair labelled allocations compatible with one designated infinite target step. The symmetric designation of the other output child is checked separately by complementation. This is finite exact geometry, not a global construction or a fibre-cap proof.

**Two-bit capacity lemma.** At a target transition q_A=1→2, the SOLE A source parent s has BOTH its input children routed to the target output bit. Consequently an output bettor gaining c>1 on that bit cannot compel the source bettor to gain c on both source children: any fair rational child factors r_0+r_1=2 have min(r_0,r_1)≤1. One output step has zero guaranteed source gain. On the following true output step the A occupancy must be t∈{1,2,3}; because ALL A descendants at that time come from the same original s, exactly t of its four length-two input extensions produce the selected two-bit output suffix. Hence t≤3, so at least ONE grandchild is excluded and the two-bit source conditional target frequency is exactly t/4≤3/4. More generally after ℓ≥1 true output steps from q_A=1, the selected length-ℓ block has q_A(final)≤3 descendants of s and conditional probability q_A(final)/2^ℓ. This is an exact finite-block capacity identity, not a computable way to predict the target block.

**Hostile limitation.** It does NOT imply that along EACH true inverse the next input child is distinguishable by the source bettor at a profitable time: even with three surviving grandchildren, one of the first-level source children can have both grandchildren still compatible, and the target output path is not known before taking the bet. q=1→2 may recur after 2→1, while q=3→2 carries the symmetric B-branch blind step. A bounded q posterior factor q(final)/q(initial) telescopes as in S143; treating visits to t≤3 as exponential profit double-counts the conditional selection. The globally fair S135 3:1↔2:2 oscillator and S141 safe positive-fold pockets reject any inferred universal detector. No simulator of degree≤2 over EVERY output was built.

Status FAIL as a universal method.

**Dynamic degree-two F2 compilation attempt.** At q=1→2 a current A cell sends both source children to the target, so an immediate source wager has no common positive factor. Choosing two preferred cells locally and filling sibling branches is not a proof that a single total fair cap-two observer follows the actual x through infinitely many nonstationary excursions. S129's stationary 2-cell compiler works when q eventually equals two; neither that hypothesis nor a computable last injury is available here. Status UNSOLVED.
