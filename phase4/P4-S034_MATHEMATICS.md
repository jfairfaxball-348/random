## 2. Exact P4-S012 pullback: coded self-avoidance

Let \(x\in CR\), let \(T\) be a total computable one-hole adaptive no-repeat scan, and let a computable nonnegative rational martingale \(d\) succeed on
\[
S_T(H(x)).
\]

Since \(H(x)\in CR\), P4-S008 implies that this winning scan transcript is a singleton fibre and hence that \(T\) queries every virtual coordinate on \(H(x)\). P4-S012 therefore supplies a self-avoiding virtual stake functional: immediately before \(T\) queries virtual coordinate \(q\), its signed fractional stake is computable from the virtual source with coordinate \(q\) withheld.

### Lemma 1 — the raw pullback is vector-self-avoiding

Fix a virtual coordinate \(q\) in local block position \(i\). Pull its P4-S012 stake functional back through \(H\). The resulting raw functional is invariant under toggling the whole raw vector \(v_i\).

**Proof.** Toggling \(v_i=H^{-1}(e_i)\) changes exactly the virtual bit \(u_i\) and fixes every other virtual coordinate. The P4-S012 stake at \(u_i\) does not query \(u_i\), so its value is unchanged. ∎

This is not ordinary raw self-avoidance. For example, a legal virtual stake at \(u_0\) may depend on already revealed \(u_2\). After pullback that datum is
\[
u_2=x_0\oplus x_1\oplus x_2,
\]
which essentially depends on each of the three raw coordinates. The stake can therefore fail to avoid every individual raw coordinate even though it avoids the coded direction \(v_0\).

### Consequence

The same P4-S012 witness does **not** in general compile coordinate-by-coordinate to a raw self-avoiding stake functional. This is stronger than merely observing that the conjugated map is not literally a scan, but it is still not a separation witness: a different raw one-hole scan may exist.

## 3. Canonical raw support evaluator for blockwise linear recodings

The preceding failure does not mean all of \(d\)'s wagers are lost. There is a canonical way to evaluate the virtual scan using raw coordinate queries.

Consider more generally a fixed invertible binary \(n\times n\) matrix \(A\), repeated independently on successive \(n\)-blocks. When \(T\) requests a virtual coordinate corresponding to row \(r\):

1. if some raw coordinate in the support of row \(r\) is still fresh, query all fresh support coordinates, holding capital on all but the last one;
2. at the last fresh support coordinate, the requested virtual bit is that raw bit XOR a parity already known from the raw history, so copy \(d\)'s current fractional wager, with the two children swapped when necessary;
3. if the entire row support was already queried, compute the virtual bit internally and advance the simulation of \(T\) without making a raw query or copying that wager;
4. repeat internal step 3 until a virtual request with fresh raw support appears.

Call a virtual stage **live** in case 1 and **spoiled** in case 3: at a spoiled stage the virtual bit on which \(d\) now wagers is already determined by the earlier raw history.

### Lemma 2 — the support evaluator is a total computable one-hole scan

For every fixed invertible binary block matrix \(A\), the construction above defines a total computable adaptive no-repeat raw scan \(S_A\) whose every transcript omits at most one raw coordinate.

**Proof.** Computability and no-repeat are immediate. An internal run of spoiled virtual requests cannot be infinite: finitely many known raw coordinates meet only finitely many finite blocks, hence determine only finitely many virtual coordinates, and \(T\) never repeats a virtual query.

It remains to bound omitted raw coordinates. In each block the raw coordinates ever queried by \(S_A\) are exactly the union of the supports of the virtual rows queried by \(T\). If \(T\) omits no row in that block, invertibility gives no zero column, so every raw column appears and is queried.

If \(T\) omits one virtual row \(r\), an omitted raw column would have all its 1s confined to row \(r\), hence its column vector would be exactly \(e_r\). An invertible matrix cannot contain two identical columns, so at most one raw column is omitted. Since \(T\) has at most one omitted virtual coordinate globally, \(S_A\) has at most one omitted raw coordinate globally. ∎

### Lemma 3 — copied live wagers form a computable raw martingale

There is a computable nonnegative rational martingale \(e\) on the output of \(S_A\) which holds on support-filler queries, copies \(d\)'s signed fractional stake at the last fresh pivot of every live virtual stage, and holds through spoiled stages.

Along the target source, if \(m_t\) denotes \(d\)'s multiplicative capital factor at virtual stage \(t\), then at corresponding virtual times
\[
\frac{d_t}{d_0}
=
\left(\prod_{t\in L}m_t\right)
\left(\prod_{t\in P}m_t\right),
\qquad
\frac{e_t}{e_0}
=
\prod_{t\in L}m_t,
\]
where \(L\) and \(P\) are the live and spoiled stages up to time \(t\).

**Proof.** At a live stage, after all other fresh support coordinates have been read, the requested virtual child is either the same as the last raw child or its complement. Child-swapping preserves the martingale equality. Holding capital on all other raw queries also preserves it. On a succeeding target path \(d\) never reaches zero, so the fractional factors used on that path are well-defined and positive. The product identities follow stage by stage. ∎

If \(d\) succeeds on \(S_T(H(x))\), then

is unbounded along the target.

**Proof.** The live product is exactly \(e_t/e_0\) and is bounded because \(S_A(x)\) is computably random. Since \(d_t/d_0\) is unbounded, the spoiled product must be unbounded. ∎

> any destruction surviving the three-bit recoding must obtain unbounded multiplicative gain from virtual wagers whose parity bit had already become determined by the earlier raw-coordinate history.

The issue is therefore not merely that one virtual hole occupies several raw coordinates. It is an **order/delay debt**: evaluating earlier virtual parities can consume the raw pivot that a later virtual wager would need.

A single fully queried block necessarily has such a debt. For example, if \(T\) queries \(u_0,u_1,u_2\) in that order, evaluating \(u_0\) consumes \(x_0,x_2\), evaluating \(u_1\) then consumes \(x_1\), and \(u_2\) is already known when its wager is finally selected.

## 5. Positive invariance beyond signed coordinate permutations

The infinitary repetition above is essential to the unresolved case. A recoding confined to finitely many source coordinates can always be absorbed because only finitely many virtual wagers need be skipped.

### Definition — finite-coordinate recoding

A **finite-coordinate recoding** is a homeomorphism \(K\) for which there is a finite set \(B\subseteq\omega\) and a bijection
\[
\kappa:2^B\to2^B
\]
such that
\[
K(x)\upharpoonright B=\kappa(x\upharpoonright B)
\]
and \(K(x)(j)=x(j)\) for \(j\notin B\).

Every such map is computable and fair-coin preserving when \(B\) and \(\kappa\) are computable finite data.

### Theorem 6 — OH is invariant under finite-coordinate recodings

For every computable finite-coordinate recoding \(K\),
\[
x\in OH\quad\Longleftrightarrow\quad K(x)\in OH.
\]

More strongly, from a one-hole scan \(T\) and computable martingale \(d\) succeeding on \(S_T(K(x))\), one uniformly constructs a raw one-hole scan \(S\) and computable martingale \(e\) succeeding on \(S(x)\).

**Proof.** Simulate \(T\).

Until \(T\) first requests a coordinate in \(B\), every virtual query lies outside \(B\), where \(K\) is the identity. Query the same raw coordinate and copy \(d\)'s fractional wager exactly.

If \(T\) first requests a coordinate in \(B\), query every still-unread raw coordinate of \(B\), holding capital throughout. The whole finite block \(K(x)\upharpoonright B\) is then computable. Advance the simulation through the current and every later \(B\)-query internally, skipping the associated \(d\)-wagers. Whenever \(T\) requests a coordinate outside \(B\), query that same raw coordinate and again copy the current fractional wager of \(d\).

The raw scan is total and no-repeat. If \(T\) never requests a coordinate in \(B\), then the one-hole condition forces \(|B|\le1\), and the raw scan omits at most that one coordinate. If \(T\) does request one, the raw scan queries all of \(B\); outside \(B\), its omitted set is contained in the virtual omitted set and therefore has size at most one.

Only finitely many \(d\)-wagers are skipped, namely those made at virtual coordinates in \(B\). Along a path on which a nonnegative martingale succeeds, every realized multiplicative factor is positive. Deleting finitely many positive factors changes capital by only one finite positive multiplicative constant. Hence the copied martingale \(e\) still succeeds. This proves the forward implication. Apply the same construction to \(K^{-1}\), which is another finite-coordinate recoding, for the converse. ∎

### Corollary 7 — a genuinely larger invariance group

OH is invariant under the group generated by computable signed coordinate permutations and computable finite-coordinate recodings.

This is genuinely broader than the P4-S033 signed-permutation class. For example
\[
K(x)_0=x_0\oplus x_1,\qquad K(x)_1=x_1,\qquad K(x)_n=x_n\ (n\ge2)
\]
is a finite-coordinate fair-coin homeomorphism but is not a signed coordinate permutation.

For finite linear blocks, the naive stronger requirement that every possible first virtual query be implementable with only one fresh raw coordinate collapses back to the signed-permutation case: every matrix row would have to have weight one, and invertibility then forces a permutation matrix. Theorem 6 gets beyond that class precisely by allowing finitely many recoding-sensitive wagers to be skipped.

## 6. Why the repeated three-bit map is the first unresolved case

Let \(H_N\) apply the displayed three-bit transform only to the first \(N\) blocks and act as the identity elsewhere. Each \(H_N\) is a finite-coordinate recoding, so Theorem 6 gives
\[
x\in OH\iff H_N(x)\in OH.
\]

The full P4-S033 homeomorphism \(H\) is the infinite block product of these recodings. Therefore any failure of OH invariance for \(H\) is necessarily infinitary: no finite number of mixed blocks can witness it.

Corollary 5 identifies the required infinitary accumulation exactly. A witness \(d\) must obtain unbounded gain from spoiled wagers across infinitely many blocks. This explains why the finite-coordinate proof cannot simply be iterated: it deletes finitely many positive factors, while the full block product may require deleting an unbounded-gain infinite subproduct.

## 9. Exact next obstruction

The displayed H converts the normalization question into a delayed-stake question.

At a spoiled virtual stage, the parity being wagered on became determined at an earlier raw time, but \(d\)'s stake may depend on virtual transcript information learned only later. If the stake were already computable at the moment the final raw pivot was exposed, it could have been placed on that pivot and would cease to be spoiled. Thus the unresolved resource is not merely a parity code but **late choice of a wager on an already raw-determined parity**.

The next bounded attack should formalize the raw determination time of every spoiled virtual bit and test whether unbounded spoiled gain can be normalized whenever the associated stake is already determined at that time, then isolate the genuinely late-decision case. A genuine \(OH\) non-invariance witness must survive that reduction; a positive theorem that eliminates late-decision spoiled gain for every repeated finite-block recoding would establish a substantially larger invariance class.
