### A148.1 — Source-permutive factorisation (PROVED INTERNALLY)
Take any total computable Cantor map G with *additive use c*: the first m output bits are computable from the first m+c input bits, for all m. Fairness is permitted but not needed for this elementary row lemma; no global fibre cap is required. Let d be any total nonnegative rational computable output martingale, let p=d+1 (a strictly positive rational martingale), and write y=G(x). At each source word s of length m+c, compute its output prefix tau of length m, and calculate the next output bits b0,b1 determined by s0,s1 respectively. Call the row *permutive* when b0≠b1 and *forced* when b0=b1.

Define a total rational nonnegative source martingale e by e(s)=1 at levels <=c, and recursively, if |s|=m+c:
- if b0=b1, let e(s0)=e(s1)=e(s);
- if b0≠b1, let e(si)=e(s)*p(tau bi)/p(tau), i=0,1.

Because p(tau)>0 and p(tau0)+p(tau1)=2p(tau), the child capitals sum to 2e(s) in each case. No source/output oracle, sheet colouring, stopping price or promise about actual fibres is used. For each x let C_x be the set of forced output indices and set
F_n(x)=product over m in C_x with m<n of p(y|m+1)/p(y|m).
The finite products are positive rational and the partition into forced/permutive steps telescopes EXACTLY:
    p(y|n)/p(empty) = e(x|n+c)*F_n(x).
Thus one ordinary total computable source martingale accounts precisely for the gains on all permutive stages, not only eventually one-cell stages. This is an exact gain attribution, NOT a new globally fair source map.

### A148.2 — Unbounded forced-gain necessary condition (PROVED INTERNALLY)
If x is computably random, the single e above is bounded on x by some finite K. If d is unbounded on G(x), so is p(y|n), and the exact identity forces sup_n F_n(x)=infinity. Every p next-bit ratio is in (0,2], hence if C_x were finite, F_n would be bounded by 2^|C_x|. Therefore the forced rows occur infinitely often and the signed sum of their log-ratios is unbounded above. This is a NECESSARY condition on ANY additive-use CR bad image, including hypothetical x∈R2 with G∈F3, but applies already to CR and hence is NOT an R2-specific breakthrough. No claim that individual forced ratios exceed 1, are uniformly effectively priced, or have monotone partial product.

### B148 — Hostile globally legal countercontrol
Let H(x)(2j)=x(2j+1) and H(x)(2j+1)=x(2j), swapping adjacent bits. It is a total computable fair involutive homeomorphism: exactly one ACTUAL complete inverse above every output, all output cylinders of length m have measure 2^-m, and use c=1 works for all m. At source length m+1, the next output bit is source-permutive when m is even (the next unread input bit), but FORCED when m is odd (a previously read input bit). Thus EVERY source has forced rows of density 1/2, even though H preserves all computably random sources by computable fair homeomorphism invariance (S001/S102 E-ISO). Infinitely many forced rows are NOT a sufficient destruction criterion. This control is global and all-output, unlike finite row counterexamples.

1. **Reversing forced gain to F2:** At a forced source row both source children emit the same output bit. To turn them into a legal F2 observer one must prescribe a new globally fair output process without an x/y oracle and prove at most TWO actual complete inverse points above EVERY output.
