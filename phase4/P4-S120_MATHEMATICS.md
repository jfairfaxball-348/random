## A. Arbitrary c.e.-open sets realized as EXACT first-key stop-change loci WITH exactly two actual inverses

**Theorem A120-1 (INTERNAL: open-stop release-and-erase realizer).** For EVERY effectively open U subset X, with a specified total effective enumeration of basic cylinders for U, there is a total computable globally fair ADDITIVE-USE-ONE map G_U:X->X satisfying ALL:
(i) |G_U^-1(y)|=2 for EVERY infinite y;
(ii) for B=[0] (source first key), the finite conditional posterior q_B(tau)=2^|tau|lambda(B intersect G_U^-1[tau]) equals 1/2 until the first release and is 0 or 1 from that release onward;
(iii) the set of output paths on which q_B changes at least once is EXACTLY U;
(iv) G_U(CR) subset CR and indeed G_U(R_k) subset R_k for EVERY fixed finite k.
This is a conserving no-go for the ENTIRE release-and-erase family, not a general CP2 result.

**Algorithm.** Source x=a u, hidden key a and a cursor into u. At output stage m, let tau be the m bits already emitted. Unless a release occurred, run the first m stages of the fixed U-enumeration, and if a word sigma enumerated by then is a prefix of tau, EMIT the unused key a (consume no new u bit), mark released and set a one-time erase flag. At the NEXT output stage discard exactly ONE unread tail bit b before emitting a subsequent fresh tail bit. At all other output stages emit and consume the next unread tail bit. Once released never test U again. (An empty word enumerated at stage zero may release at stage zero.) Decisions are finite computations on prior output, hence online and total. By stage m it has inspected at most m tail bits plus a, so first m output bits use at most first m+1 source bits, including the release/erase steps.

**Complete infinite inverse proof.** For any infinite target y, replay this output-determined release schedule. If no release ever occurs, y notin U and the complete fibre is {0y,1y}. If the unique release occurs at output index t, write y=rho c v with |rho|=t, c=y_t. The complete fibre is exactly {c rho 0 v, c rho 1 v}: the key is forced to be c and one discarded source bit is unconstrained. Each proposed inverse produces all of y, with the same release schedule and exactly one erasure; conversely there can be no other inverse because all other source coordinates are forced by the emitted bits. Thus these are TWO actual infinite paths for EVERY output, including limiting nonrelease paths and every boundary point. In the release case y differs from source TAIL u=rho b v in at most ONE coordinate t; in the nonrelease case y=u.

**Cylinder-level fairness, including off-path continuations.** At any output length m without a release so far, the two compatible (m+1)-bit source words are 0tau and 1tau. If release has already occurred at index t<m, the compatible words are c rho 0 v|_(m-t-1) and c rho 1 v|_(m-t-1), of length m+1. Both are distinct, and every source word in either cylinder emits tau. There are exactly two such cylinders of measure 2^-(m+1), so lambda(G_U^-1[tau])=2^-m for every tau, not just an exhibited path. The output-trigger rule cannot see key a before its emission; it is independent of the previously emitted tail, confirming fairness by a second conditional-independent-fresh-bit argument. No hidden extra inverse can appear from a limit of temporary candidates.

**Posterior and stopping event.** For tau before release the two finite source words have opposite keys; q_B(tau)=1/2. Once release at t<m, both source words have key tau_t and q_B(tau)=1 if tau_t=0, else 0. The first change occurs iff replay eventually recognizes some enumerated sigma prefix y; equivalently y in U. Each finite posterior is rational and computable; the unbounded first-change price is lambda(U), which need NOT be a computable real.

**Whole-class CR and R_k no-go.** For actual source x=a u, the output is either u or u with exactly one coordinate flipped (the released a replaces erased b at finite index t). Fixed-prefix deletion and each fixed finite-coordinate XOR homeomorphism preserve every R_k by S112/S113. Although t is not uniformly computable on nonrelease points, for each individual source it is a fixed finite integer, so the pointwise conclusion is valid. Section B below strengthens this with ONE explicit rational compiler for all possible finite edits and all U without pricing lambda(U).

This realizer has non-onto first-key component ranges whenever U has a triggered output ending in each possible released-key bit. Define I_a=G_U([a]X). By the exact inverse description I_0 intersect I_1=E=X\U (the outputs whose two inverses have opposite initial keys), while every output in U has both inverses within the uniquely determined initial-key cone. ## B. One coherent TOTAL rational capital compiler for ALL finite-coordinate edits

Let d be ANY total nonnegative rational output martingale, and choose rational p_i=2^(-i-2) for i>=0 (sum_i p_i=1/2). For a finite source-tail word s of length n set

D(s) = sum_{F subset {0,...,n-1}} [product_{i in F} p_i * product_{i<n, i notin F}(1-p_i)] d(s xor 1_F).

**Theorem B120-1 (INTERNAL: uniform finite-edit mixture).** D is ONE total computable nonnegative RATIONAL ordinary martingale, computable by a finite rational sum at every prefix, and if there exists ANY finite coordinate set F such that d succeeds on u xor 1_F, then D succeeds on u. In particular, from the index for d alone it uniformly gives a source martingale witnessing non-CR of ANY x=a u for which d succeeds on G_U(x), simultaneously for ALL c.e. U, even noncomputably priced ones.

**Proof.** At a parent s the extra flip coin p_n on the new coordinate merely permutes its two children. Average D(s0),D(s1) over the fair next bit; the martingale equation for d cancels the flip, and the existing finite flip weights sum to D(s). Hence D(s0)+D(s1)=2D(s), with D(empty)=d(empty). For any fixed finite F and n>max F, among the summands choose precisely flips F at depth n. Its coefficient is [product_{i in F}p_i][product_{i<n, i notin F}(1-p_i)] >= (1/2)product_{i in F}p_i >0: the product of 1-p_i is >=1-sum_i p_i=1/2. Therefore D(u|n) dominates a FIXED positive multiple of d((u xor F)|n) at all sufficiently large n. Unbounded limsup succeeds. Empty F is permitted with coefficient >=1/2. Lift to original source by setting D_source(empty)=D(empty), D_source(a s)=D(s); its first-bit children both equal D(empty), and beyond that it is a rational martingale. For G_U each image is either u or u xor {t}, so one D_source works with NO index of U and no paid infinite stopping-event probability. QED.

This is an explicit coherent SOURCE account, independent of S109's generic c1 compiler, and strictly refutes the proposed INFERENCE that an undecidable infinite event price precludes all ordinary rational compilers. It does NOT solve the requested all-additive-use-two compiler: a map that performs infinitely many edits with unbounded unknown support falls outside the fixed-finite-F domination argument. Likewise S119's asynchronous two-ghost maps need not be finitely edit-equivalent to source tails.

**Hostile source test.** If p_i had nonsummable total mass, the fixed-F coefficient could converge to zero, so the proof would fail. If the mixing law depended on future output rather than an independent finite flip mask, the child-average identity would fail. Merely having an infinite computable-real sum is NOT enough for ordinary rational CR; here every prefix expression is a finite rational sum. The source first-key extension is essential to avoid silently treating a u as u.

## C. A fat noncomputable boundary AND an effective beta certificate on a genuine ramified subset

**Construction C120-1.** Split coordinate positions into successive computable blocks of lengths L_j=j+5, j>=0. Let W be the c.e.-open event that at least one COMPLETE block is all zero. Let K0=X\W, the block-product closed class forbidding 0^L_j in every block. Put p=lambda(K0)=product_j(1-2^-L_j); p is a positive COMPUTABLE real, p>=1-sum_j2^-L_j=15/16, and w=lambda(W)=1-p<=1/16 is computable. Every cylinder has an extension that completes an all-zero later block, so W is dense and K0 is nowhere dense. Uniform tail products compute lambda(K0 intersect [s]) for every finite s.

Let c_e=0^(2e+1)1, length 2e+2, weight 4^(-e-1), a disjoint prefix-code family of total measure 1/3. Fix an undecidable c.e. halting set H and alpha_H=sum_{e in H}4^(-e-1). Define V=[1]W union (union_{e>=0} [c_e]W), with [c]W={c z:z in W}; define U=V union (union_{e in H}[c_e]). This U is c.e.-open and DENSE: W is dense within each of the disjoint [1] and [c_e] cones, and these cones cover all outputs except 0^omega. Their contributions have disjoint measures. Precisely

lambda(U)=(1/2+1/3)w + p alpha_H = 5w/6 + p alpha_H;
lambda(E)=1-5w/6-p alpha_H >= 2/3-w/2 >0.

Since p,w are computable with p>0, a computable lambda(U) would compute alpha_H; base-four separation of its digits would decide H, contradiction. Thus E=X\U is an effectively closed POSITIVE-MEASURE nowhere-dense set with NONCOMPUTABLE measure. For its G_U, D_1={y: the two actual inverse points differ at their FIRST source bit}=E exactly, so the fibre stratum has noncomputable mass. This is consistent with S112's warning that effective closedness does NOT imply computable measure. The map is NONLINEAR: S116's globally fair affine exact-two maps have D_1 either empty or all of X, whereas here D_1 is proper and positive.

**Ramification and actual CR sources.** For U open, once an output y has released at t, a sufficiently long source neighbourhood fixes the key and the erased bit, giving an injective restriction. If y in E=boundary(E) (U dense), x=a y has no locally injective source neighbourhood: for any [a y|n], choose a nearby triggered output with release time t>=n (possible from density and the absence of any release on y's first n steps), choose its output bit at t to be a, then the two distinct erased-bit inverse sources both extend a y|n and have the same output. Because CR has full lambda-measure, this contains ACTUAL CR sources 0y and 1y over many y in E; their common output y is necessarily CR (finite-prefix deletion). **C120-2 (priced injective certificate without global D1 mass).** Consider B_a={a 1 v:v in K0} within the source.
