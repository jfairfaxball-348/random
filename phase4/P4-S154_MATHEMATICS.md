## A154.1 — Single-source-neighbourhood injectivity firewall (PROVED INTERNALLY)

**Theorem.** For ANY total computable globally fair Cantor map `G:X→X`, with NO fibre cap and NO additive-use bound, any `x∈CR`, and any finite word `s⊑x`, if `G|[s]` is injective then `G(x)∈CR`. More generally for any total computable `G` not necessarily fair, local injectivity preserves CR from `λ` to the computable output measure `G_*λ`.

**Proof.** Let `B=[s]`, `p=λ(B)=2^(-|s|)>0`, and `λ_B(A)=λ(A∩B)/p`. This is a computable probability measure on X. For every output cylinder `[τ]`, the set `B∩G^-1[τ]` is EFFECTIVELY CLOPEN because G is total computable on computably compact Cantor space. Its measure is an EXACT rational number. Thus `ν_B=G_*λ_B` is a computable probability measure, uniformly from G,s.

Since G is injective on compact B, `G:B→G(B)` is a homeomorphism. Its inverse is partial computable on the computably compact image: given y in G(B) and requested input prefix length k, search an output length m for which **all** B-source points whose G-output agrees with `y↾m` share the same k-prefix. This search halts by compactness plus injectivity; each finite condition is decidable from clopen source preimages. The inverse never needs an oracle for x, a nondecidable sheet label or a future output path. Extend to a measure isomorphism on supported computable spaces `(B,λ_B)` and `(G(B),ν_B)`. By the verified effective-isomorphism computable-randomness theorem used in S003/S102, if x is `λ_B`-CR then y=G(x) is `ν_B`-CR. Because B is a decidable clopen cylinder, λ-CR of x∈B implies λ_B-CR (finite-prefix conditioning cannot create a total rational winner).

Let `ν=G_*λ` (ν=λ if G is fair). For EVERY Borel A,
`ν_B(A)=λ(B∩G^-1 A)/p ≤ ν(A)/p`.
So for ALL output cylinders `[τ]`, `ν_B[τ]≤p^-1ν[τ]`. The standard computable-measure ratio characterization of CR (DEF-0036, S003) now transports ν_B-CR to ν-CR: any computable probability test measure `η` whose ratio `η[y↾n]/ν[y↾n]` diverged would give `η[y↾n]/ν_B[y↾n] ≥ p η[y↾n]/ν[y↾n]`, a contradiction. Zeros on ν_B cylinders cannot occur on a ν_B-computably-random y. Therefore y is ν-CR, which for globally fair G is ordinary CR. QED.

**Audit of hypotheses:** The patch B is genuinely clopen and given by a FINITE word; its conditional probability p is rational, not a limit. Injectivity on B is an additional mathematical HYPOTHESIS, not a generally decidable property of G. The inverse search is valid ON G(B); no total section across unrelated output fibres is claimed.
