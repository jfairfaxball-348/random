## 1. What the P4-S011 conversion actually uses

P4-S011 fixed a computably random sequence X and a weak-truth-table autoreduction M. The scan conversion never used the computable wtt use bound. It used only the following target-side facts at the successive sentinels chosen by the scan:

1. the relevant computation eventually has a finite visible halt;
2. that computation does not query the sentinel being predicted;
3. its output is the target sentinel bit.

It also did not require predictions at coordinates which the scan had already exposed as fillers.

This can be stated without wtt terminology.

### Definition — sentinel-local self-avoiding partial predictor

Fix a partial oracle functional P. Run the following least-fresh process on a source X.

At the start of an epoch let j be the least coordinate not yet revealed. Keep j withheld. Repeatedly reveal the least fresh coordinate different from j while simulating P on input j from the revealed oracle answers. The epoch triggers when a finite binary halting computation P(j)=b is visible using only revealed coordinates and not querying j; then reveal j and start the next epoch.

Say that P is a sentinel-local correct partial predictor along X if every epoch generated by this process triggers after finitely many fillers and the visible prediction is X(j).

This is an operational property along X. P may diverge, query its input, or predict incorrectly on other oracles or on coordinates which never become sentinels. No totality on sibling oracles is assumed.

### Theorem 1 — sentinel-local prediction is sufficient

If a computably random X has a sentinel-local correct partial predictor P, then the P4-S011 least-fresh construction yields an everywhere-total computable adaptive no-repeat scan F such that:

- F preserves fair coin;
- every fibre has cardinality at most two;
- X lies on an all-trigger singleton fibre; and
- one computable output martingale succeeds on F(X).

#### Proof

The scan is exactly the defining least-fresh process, interpreted on every source rather than only X.

At every finite transcript, either a finite binary halt avoiding the current sentinel is visible, in which case the scan queries that fresh sentinel, or no such halt is visible, in which case it queries the least fresh non-sentinel coordinate. Hence one fresh coordinate is queried at every output stage, so the scan is everywhere total, computable and no-repeat.

For any output word of length m, the m queried source coordinates are pairwise distinct and are computably determined from the earlier output bits. The preimage therefore fixes exactly m independent fair bits, so it has measure 2^{-m}. Thus F preserves fair coin.

If an epoch never triggers, its filler rule eventually queries every coordinate except its sentinel, so the corresponding fibre has exactly two points. If every epoch triggers, each current least-unqueried sentinel is consumed; the successive sentinels move right and every coordinate is eventually queried, so the fibre is a singleton. Thus the global fibre bound is two.

On X every epoch triggers and predicts the sentinel correctly. The output martingale holds its capital fixed on filler bits and bets all capital on the visible predicted bit at a sentinel. It doubles once per epoch and is therefore unbounded. ∎

### Corollary 2 — the wtt hypothesis is stronger than the conversion needs

Any target-total Turing autoreduction of X — a partial oracle machine A with A^X(n)=X(n) for every n and whose input-n computation never queries n — supplies the sentinel-local property. Persistent fillers eventually reveal the finite oracle answers used by each target computation.

Consequently the computable wtt use bound in P4-S011 is not needed by the scan conversion. It remains useful only because SRC-0067 / SRC-0068 / THM-0076 provide the already-inspected existence theorem for a computably random source with that stronger property.

Even target-total autoreducibility is stronger than the exact operational need: the least-fresh conversion only needs correct visible computations on the coordinates that actually become its sentinels. No strict separation theorem between these hypotheses is claimed here.

## 2. The exact stake-level weakening

The full-wager bit predictor is still stronger than necessary. The same geometry works for partial fractional wagers.

Let B be a partial oracle functional whose visible halts output rational stakes theta in [-1,1]. Use the same least-fresh process, withholding the current sentinel j until a finite computation B(j)=theta is visible without querying j. On the sentinel bit b, let capital be multiplied by

1 + theta(2b-1).

If the target X makes every generated epoch trigger and the resulting capital sequence is unbounded, call this a target-winning self-avoiding partial stake spine.

### Theorem 3 — target-winning partial stakes are sufficient

A computably random X carrying a target-winning self-avoiding partial stake spine yields an exact global-k=2 destroyer by the same least-fresh scan.

#### Proof

Totality, no-repeat, fair-coin preservation and the global fibre calculation are unchanged from Theorem 1. Define the output martingale to hold capital fixed on fillers. At a visible stake theta with current capital C, assign the two sentinel children

C(1-theta) and C(1+theta).

They are nonnegative and average to C. Along F(X) these are exactly the prescribed stake updates, which are unbounded by hypothesis. ∎

Theorem 3 identifies the weakest natural data used by this particular conversion: a c.e.-visible self-avoiding wager at every generated sentinel plus unbounded target capital. It removes the wtt use bound, predictions at filler coordinates, and the requirement that every triggered wager be an error-free all-in bit prediction.

This is a structural sufficiency statement for the P4-S011 architecture, not a claim of an absolute weakest logically equivalent hypothesis among all possible formulations.

P4-S011 is the special case theta=+1 for prediction 1 and theta=-1 for prediction 0, with every target wager correct.

## 3. Converse inside the global-k=2 no-repeat scan subclass

Now let T be an everywhere-total computable adaptive no-repeat scan whose every infinite transcript omits at most one source coordinate. Let x be computably random, let y=F_T(x), and let d be a nonnegative rational-valued computable martingale succeeding on y. Rational-valued martingales suffice for computable randomness under DEF-0004.

By the settled P4-S008 fixed-sentinel theorem, T cannot omit any coordinate on a computably random source on which an output martingale succeeds. Hence the winning source lies on a singleton fibre and T eventually queries every coordinate.

### Lemma 4 — every singleton winning scan induces a self-avoiding stake functional

There is a partial oracle functional S such that, for every coordinate j:

- S^x(j) halts;
- the computation S^Z(j), whenever it halts, never queries Z(j);
- its output is the exact signed fractional stake that d makes immediately before T queries j on x.

#### Construction

On oracle Z and input j, simulate T from the empty transcript.

Whenever T asks a coordinate k different from j, query Z(k), append that bit to the simulated T transcript, and continue. If T is about to query j, stop before asking Z(j). Let tau be the simulated transcript at that point.

Write

C=d(tau),  C_0=d(tau0),  C_1=d(tau1).

If C>0, output

theta=(C_1-C_0)/(2C).

If C=0, output theta=0.

Because d is nonnegative and C=(C_0+C_1)/2, theta lies in [-1,1] and is rational. The computation is self-avoiding by construction. On x it halts for every j because T eventually queries every coordinate.

Moreover

C(1-theta)=C_0,
C(1+theta)=C_1.

Therefore, when the coordinates are taken in T's actual query order on x, the stake signals produced by S reproduce d's capital exactly. Since d succeeds, this scan-relative self-avoiding partial stake scheme succeeds as well. ∎

### Corollary 5 — an exact converse holds at the stake level

Within the global-k=2 adaptive no-repeat scan subclass, every computably-random singleton-spine winning scan induces a total-on-that-source self-avoiding partial stake functional whose wagers, in the original scan order, reproduce the winning output martingale.

Thus the P4-S011 mechanism has a genuine converse after replacing “correct bit autoreduction” by “self-avoiding signed stake functional” and retaining the scan's query order.

This converse does not use k=2 after singletonhood has been obtained; k=2 enters through the settled P4-S008 argument forcing singletonhood for a computably random winning source.

## 4. How much bit prediction follows from the stake converse?

At a nonzero stake, define the favoured bit to be 1 when theta>0 and 0 when theta<0.

### Lemma 6 — infinitely many favoured-bit predictions are correct

Along a path on which the reproduced capital is unbounded, there must be infinitely many stages at which theta is nonzero and the favoured bit is correct.

If only finitely many such correct biased wagers occurred, then after the last one every nonzero wager would be wrong and would multiply capital by a factor strictly below one, while zero wagers would leave capital unchanged. Capital could not become unbounded. ∎

So every singleton-spine winning scan gives infinitely many correct self-avoiding predictions in this weak “predict whenever the martingale expresses a bias” sense.

But errors need not disappear.

### Lemma 7 — all-in wagers are error-free on a succeeding path

If |theta|=1 and C>0, the unfavoured child has capital zero. A nonnegative martingale which reaches zero stays zero on every extension. Therefore every all-in wager occurring along a succeeding path must be correct.

Hence any winning scan whose relevant wagers are all-in yields an error-free partial bit predictor at those wagering coordinates. P4-S011 lies exactly in this special case.

### Why arbitrary success does not force the P4-S011 bit-autoreduction form

Ordinary martingale success does not require all-in wagers and does not require every favoured-bit prediction to be correct.

For example, a martingale which repeatedly stakes one half of its capital on bit 0 multiplies capital by 3/2 on 0 and by 1/2 on 1. Along the periodic pattern 001, each three-step block multiplies capital by

(3/2)^2(1/2)=9/8>1,

so capital is unbounded even though the favoured-bit prediction is wrong at every occurrence of 1, hence infinitely often.

This is only a martingale-logic example. It is not asserted to be a computably random source, a global-k=2 witness, or a counterexample to the existence of some different error-free predictor.

A second obstruction is order. The functional S in Lemma 4 reproduces d when its stakes are encountered in T's original adaptive query order. Re-running S inside a different least-fresh comb can change the order of wagering coordinates, and no theorem here says the resulting capital remains unbounded.

Therefore P4-S012 does not establish that every singleton-spine winning scan yields a P4-S011-style all-correct partial autoreduction. The exact unconditional converse obtained is the stake-level converse of Corollary 5; error-free bit prediction follows under the additional all-in condition.

## 5. Successes and failures

Successful:

1. The wtt use bound is removed from the P4-S011 conversion.
2. Full prediction of every source coordinate is removed: only the recursively generated sentinels need target-correct visible predictions.
3. The sufficient hypothesis is weakened further to target-winning self-avoiding partial rational stakes.
4. Every computably-random winning source for a global-k=2 no-repeat scan is already singleton by P4-S008, and from such a scan one can compute a self-avoiding stake functional total on that source.
5. In the original scan order those stakes reproduce the output martingale exactly.
6. Every succeeding stake spine has infinitely many correct favoured-bit wagers, and all-in wagers on a succeeding path are necessarily correct.

Failed or deliberately not claimed:

1. No strict separation is proved between wtt autoreducibility, target-total Turing autoreducibility, sentinel-local prediction, and the stake-spine property on computably random sequences.
2. An arbitrary winning martingale does not by its capital behavior alone force every favoured-bit prediction to be correct.
3. No general conversion from the scan-relative stake functional back into a least-fresh all-correct predictor is proved, because query order can matter.
4. No theorem says every singleton-spine winning scan has some other error-free partial autoreduction beyond the stake scheme constructed here.
5. No settled P4-S005 through P4-S011 route is reopened.
