## 1. Theorem 1: the exact halving mechanism

F₂, width-two strategies (G,d), the savings transform d = A + B (S082 Lemma 2.4; 0 ≤ A < 2, B non-decreasing, E_λ[B_∞] ≤ 1), and μ_e := (2+B^e_∞)·λ on outputs are as in P4-S087 §1. Every μ_e is a finite measure, μ_e ≪ λ, of total mass ≤ 3.

**Definition 1.1 (split potentials).** Let P, C be clopen with λ(P) > 0. For an output string w of length t put:
* c^P(w) := 1 if G⁻¹[w] ∩ P ≠ ∅;
* s^{P,C}(w) := 1 if G⁻¹[w] ∩ P meets both C and its complement;
* Ψ(P,t) := λ(P)⁻¹ Σ_{w∈2^t} 2^{−t} d(w) c^P(w), and γ(P,C,t) := λ(P)⁻¹ Σ_{w∈2^t} 2^{−t} d(w) s^{P,C}(w).

These are computable rationals, uniformly in (indices of) G, d, P, C and t. C is a **balanced split** of P if λ(P∩C) ∈ [¼λ(P), ¾λ(P)]; this is decidable.

**Lemma 1.2.**
(i) Ψ(P,t+1) ≤ Ψ(P,t) and γ(P,C,t+1) ≤ γ(P,C,t).
(ii) λ(P)⁻¹ ∫_P X_t dλ ≤ Ψ(P,t), where X_t(x) := d(G(x)↾t).
(iii) With α := λ(P∩C)/λ(P) ∈ (0,1): α·Ψ(P∩C,t) + (1−α)·Ψ(P∖C,t) = Ψ(P,t) + γ(P,C,t). Hence the smaller of Ψ(P∩C,t) and Ψ(P∖C,t) is at most Ψ(P,t) + γ(P,C,t).
(iv) Along every output y, s^{P,C}(y↾t) is eventually equal to s_∞(y) := 1 iff G⁻¹(y) = {x,x′} with x ≠ x′, x, x′ ∈ P and exactly one of them in C. Consequently

  lim_t γ(P,C,t) ≤ λ(P)⁻¹ μ{y : s_∞(y) = 1}, where μ := (2+B_∞)λ.

*Proof.*
* (i) G⁻¹[wb] ⊆ G⁻¹[w], so c^P(wb) ≤ c^P(w) and s^{P,C}(wb) ≤ s^{P,C}(w). Since d is a non-negative martingale, d(w0)u(w0)+d(w1)u(w1) ≤ 2d(w)u(w) for u ∈ {c^P, s^{P,C}}.
* (ii) If x ∈ P then x ∈ G⁻¹[G(x)↾t] ∩ P, so 1_P(x) ≤ c^P(G(x)↾t). Fairness of G turns the output sum into ∫X_t·c^P(G(·)↾t) dλ.
* (iii) G⁻¹[w] ∩ P is the disjoint union of its parts in C and outside C, so c^{P∩C} + c^{P∖C} = c^P + s^{P,C}. Multiply by 2^{−t}d(w), sum over w, and use α·λ(P∩C)⁻¹ = (1−α)·λ(P∖C)⁻¹ = λ(P)⁻¹.
* (iv) The sets G⁻¹[y↾t] ∩ P ∩ C and G⁻¹[y↾t] ∩ P ∖ C are compact and decreasing in t, with intersections G⁻¹(y) ∩ P ∩ C and G⁻¹(y) ∩ P ∖ C. A decreasing sequence of nonempty compact sets has nonempty intersection, so s^{P,C}(y↾t) = 1 for all t iff both intersections are nonempty. With |G⁻¹(y)| ≤ 2 this is s_∞(y) = 1. The indicator is non-increasing, hence eventually constant. Finally γ(P,C,t) = λ(P)⁻¹E_λ[X_t s^{P,C}(y↾t)] with X_t ≤ 2 + B_∞ integrable, and dominated convergence gives the bound. ∎

No width modulus is used. Phantoms disappear along each output by compactness alone, as in P4-S087 Lemma 1.

**Definition 1.3 (halving-dispersible).** A class 𝒱 of width-two strategies, uniformly partial computable with an arithmetically defined set of valid indices, is **halving-dispersible** if the following holds for every finite set F of valid strategies, every choice of positive rational weights (w_e)_{e∈F}, every clopen P with λ(P) > 0 and every ε > 0. There is a balanced split C of P such that

  Σ_{e∈F} w_e μ_e(Sep_e(P,C)) ≤ ε·(λ(P) + Σ_{e∈F} w_e μ_e(Pair_e(P))),

where Pair_e(P) := {y : G_e⁻¹(y) = {x,x′}, x ≠ x′, x, x′ ∈ P} and Sep_e(P,C) := {y ∈ Pair_e(P) : exactly one preimage lies in C}.

The condition is relative: a split may separate only a small fraction of the capital-weighted pairs that P still contains. If C is a fresh halving with Sep_e = ∅ for all e, then C is exactly invariant for every partner involution inside P.

**Theorem 1 (halving survivor theorem).** Let 𝒱 be halving-dispersible and contain (id, d) for every rational-valued computable martingale d. Then there is z ∉ MLR on which no strategy of 𝒱 succeeds. In particular z ∈ CR. If 𝒱 contains (G,d) for every rational computable d whenever it contains some (G,d′), then G(z) ∈ CR for every such G. The witness is computable from a finite iterate of the jump of the validity set.

*Proof.* Run the guessed runs R(ε) of S082 §4 (weights w_e, potentials Φ := Σ_{e∈A} w_eΨ^e and Γ := Σ_{e∈A} w_eγ^e on clopen states), with state (P, τ), initially P = 2^ω, τ = 0. Put ℓ_i := 5(i+1) and ε_i := 2^{−(i+4)}/ℓ_i.
* *Stage (a)* is S082's verbatim: on ε(i) = 1, compute P̂ := Ψ^i(P,τ), set w_i := 2^{−(i+2)}/(1+P̂), and add i to A.
* *Stage (b), repeated ℓ_i times.* Dovetail over pairs (C,t), where t ≥ τ and C ranges over the clopen sets given by finite lists of cylinders that are balanced splits of P. Halt at the first pair with Γ(P,C,t) ≤ ε_i. Let P_b be whichever of P∩C and P∖C has the smaller Φ(·,t) (P∩C on ties). Set P := P_b and τ := t.
* *Stage (c).* Output P^ε_i and τ^ε_i.

*Halting on true runs.*
* By Lemma 1.2(ii) applied to B alone and monotone convergence, E_λ[B^e_∞ 1_{Pair_e(P)}] ≤ λ(P)·lim_tΨ^e(P,t) ≤ λ(P)Ψ^e(P,τ). Since μ_e = (2+B^e_∞)λ and Σ_e w_e ≤ ½,

  Σ_{e∈A} w_e μ_e(Pair_e(P)) ≤ λ(P)·(1 + Φ(P,τ)) < 3λ(P)

  while the invariant below keeps Φ < 2.

*Invariant.*

* So the ℓ_i repetitions raise the carried bound by at most ℓ_iε_i = 2^{−(i+4)}. Stage (a) adds less than 2^{−(i+2)}.

*Martin-Löf test.*

Domination is given by Lemma 1.2(ii), exactly as in P4-S088 Theorem C. They yield z ∈ S with d̄_e(G_e(z)↾t) ≤ 2 + 2/w_e for every valid e and every t. Every valid d_e is then bounded along G_e(z). Validity is arithmetical, so the true runs, S and the leftmost point of S∖O are computable from a finite iterate of the jump. ∎

## 2. Proposition 2: the exact structure of the two-frame instance

Notation is that of P4-S088 §6. Controls are a_j := x_{2j}, data b_j := x_{2j+1}, and

  K_mix: b′_j = b_j ⊕ b_{j−2} ⊕ (1⊕a_j)·b_{j−1}  (b_{−1} = b_{−2} := 0).

K′_mix exchanges the roles: its data are b̃_j := x_{2j}, recoded by b̃′_j = b̃_j ⊕ b̃_{j−2} ⊕ (1⊕x_{2j−1})·b̃_{j−1}, with x_{−1} := 0. Write ψ_q := K_mix⁻¹∘flip_{2q+1}∘K_mix for the partner involution of the fixed-hold scan U_q, and ψ′_p := K′_mix⁻¹∘flip_{2p}∘K′_mix for that of U′_p.

**Solution spaces.** For a control sequence a, let S(a) be the set of δ ∈ 2^ℕ with δ_j = δ_{j−2} ⊕ (1⊕a_j)δ_{j−1} for all j ≥ 2.
* S(a) is a two-dimensional F₂-space, parametrised by (δ₀, δ₁).
* The state map (δ_{j−1}, δ_j) ↦ (δ_j, δ_{j−1} ⊕ (1⊕a_{j+1})δ_j) is invertible, so a nonzero solution never has two consecutive zeros.
* For a window W of data positions [J, J+R) with J ≥ 2 and R ≥ 2, let S_W(a) be the set of restrictions to W of the sequences δ on [J−1, J+R) satisfying the recursion for J+1 ≤ j < J+R. It is two-dimensional, parametrised by (δ_{J−1}, δ_J), and depends only on the window controls a_{[J+1,J+R)}.
* Restriction S(a) → S_W(a) is a bijection. It is injective because δ|_W = 0 forces the state (δ_J, δ_{J+1}) = (0,0), and hence δ = 0 by invertibility. Both spaces have dimension 2.
* S′(x) and S′_W(x) are defined in the same way from the K′_mix recursion, whose coefficient at j is 1 ⊕ x_{2j−1}. On the window this coefficient uses only the window data b_{[J,J+R−1)}.

**Proposition 2.**
(a) ⟨ψ₀, ψ₁⟩ = {(a,b) ↦ (a, b ⊕ v(a)) : v ∈ {0, δ⁰, δ¹, δ⁰⊕δ¹}}. Here δ⁰(a), δ¹(a) form a basis of S(a), so for every x the orbit of x under ⟨ψ₀,ψ₁⟩ is exactly {(a, b⊕v) : v ∈ S(a)}. Symmetrically, ⟨ψ′₀, ψ′₁⟩ translates the even coordinates by S′(x), which depends only on the odd coordinates.
(b) Let F be a finite set of K_mix-coordinates, all below 2J (that is, flips of a_p and b′_q with p, q ≤ J−1). On the raw window [2J, 2J+2R), the involution K_mix⁻¹∘flip_F∘K_mix leaves the controls unchanged and translates the data by an element of S_W(a), possibly 0. That element depends on x↾2J. Symmetrically for K′_mix with S′_W.
(c) Hence a clopen set C̃ depending only on the window coordinates satisfies the following equivalence. It is exactly invariant under every FD₂^{K_mix}- and FD₂^{K′_mix}-partner involution whose flips lie below the window iff it is invariant under the two order-four groups
  T_W := {τ_s : s ∈ F₂²} and T′_W := {τ′_r : r ∈ F₂²}, acting on the window coordinates. Here:
  * τ_s(a,b) := (a, b ⊕ δ^{(s)}(a)), where δ^{(s)} solves the K_mix recursion for j ∈ [J, J+R) from the incoming state (δ_{J−2}, δ_{J−1}) = s;
  * τ′_r(a,b) := (a ⊕ δ′^{(r)}(b), b), where δ′^{(r)} solves the K′_mix recursion for j ∈ [J+1, J+R) from (δ′_{J−1}, δ′_J) = r, with coefficients 1 ⊕ b_{j−1} taken from the window data.
  By linearity in the parameter, each is a group of four commuting window maps, and {δ^{(s)}(a) : s} = S_W(a) and {δ′^{(r)}(b) : r} = S′_W(b) for every a, b. Since invariance is pointwise in a (resp. b), invariance under T_W is the same as invariance under every control-dependent data translation by S_W(a), and likewise for T′_W.
  For the fixed-hold maps U₀ and U′₀, the λ-separation of C̃ is a positive mixture of the separations under the three nonzero elements of T_W, respectively T′_W. The mixture weights are the probabilities of the incoming states, which tend to ⅓ each for the K_mix chain.

*Proof.*
(a)
* By the S088 Proposition D computation, ψ_q translates the data by δ^q(a): δ^q_j = 0 for j < q, δ^q_q = 1, and δ^q_j = δ^q_{j−2} ⊕ (1⊕a_j)δ^q_{j−1} for j > q. The controls are unchanged.
* δ⁰ has (δ₀, δ₁) = (1, 1⊕a₁) and δ¹ has (δ₀, δ₁) = (0,1). Both satisfy the recursion for j ≥ 2, so both lie in S(a), and they are independent.
* Translations by functions of the unchanged controls commute and compose additively. So the group they generate is {id, ψ₀, ψ₁, ψ₀ψ₁}, with translation vectors 0, δ⁰, δ¹, δ⁰⊕δ¹.
* For K′_mix the same computation applies with even and odd exchanged. Its coefficient 1 ⊕ x_{2j−1} uses only odd coordinates, which ψ′_p leaves unchanged.

(b)
* A data flip at q is ψ_q, whose window action is translation by δ^q|_W ∈ S_W(a).
* A control flip at p (K-coordinate 2p): raw a_p flips, and the data change ε satisfies ε_j = 0 for j < p and ε_p = b_{p−1}. For j > p it satisfies ε_j = ε_{j−2} ⊕ (1⊕a_j)ε_{j−1}, with a_j unchanged for j ≠ p. This follows by subtracting the two inverse recursions b_j = b′_j ⊕ b_{j−2} ⊕ (1⊕a_j)b_{j−1}, the term at j = p contributing (1⊕a_p)b_{p−1} ⊕ a_p b_{p−1} = b_{p−1}. So above p the change is 0 or a solution, and its window restriction lies in S_W(a).
* A finite set F of flips composes such maps. The window controls never change, so S_W(a) is the same group throughout and the composite acts on W by translation by an element of S_W(a).

(c)
* By (b), every relevant involution acts on the window through T_W or T′_W, so invariance under T_W ∪ T′_W suffices.
* Conversely, by (a) the window action of ψ₀ (resp. ψ₁) is τ_s with s the incoming state (δ⁰_{J−2}, δ⁰_{J−1}) (resp. that of δ¹). This state is a function of the controls below the window, and every nonzero value occurs with positive probability. The same holds for ψ′₀ and ψ′₁, whose parameter r = (δ′_{J−1}, δ′_J) is a function of the coordinates below 2J. So invariance under ψ₀ and ψ₁ for all x forces invariance under all three nonzero elements of T_W, and likewise for T′_W.
* The K_mix state chain (0,1) → (1, 1⊕a), (1,1) → (1, a), (1,0) → (0,1) has the uniform stationary law on its three states and is aperiodic. ∎

So in a fresh window the two-frame union acts through ⟨T_W, T′_W⟩: two commuting order-four groups of control-dependent data translations and data-dependent control translations, which do not commute with each other. This is the precise nonlinear object behind P4-S088 Proposition D.

## 3. Level decomposition and the spectral barrier for causal frames

**Causal involutions.** A computable fair homeomorphism ψ is *causal* if ψ(x)_n = x_n ⊕ f_n(x↾n) for all n; equivalently, ψ is an automorphism of the binary rooted tree. Compositions and inverses of causal maps are causal. K_mix, K′_mix, every coordinate flip, and every partner involution K⁻¹∘flip_F∘K of a fixed-hold one-hole scan after a causal frame K are causal. For a causal involution, ψ² = id gives f_n(ψ(v)) = f_n(v) for every v ∈ {0,1}^n.

Fix causal involutions ψ₁, …, ψ_m.
* **Level operators.** For n ≥ 0 and v ∈ {0,1}^n write ψ_i(v) := ψ_i(x)↾n for any x ⊒ v, and c_i(v) := f^{(i)}_n(v), the bit telling whether ψ_i flips coordinate n on [v].
* The **signed level operator** on ℓ²({0,1}^n, uniform) is M_n h(v) := (1/m)Σ_i (−1)^{c_i(v)} h(ψ_i(v)). It is self-adjoint, because ψ_i is an involution and c_i(ψ_i v) = c_i(v).
* The **unsigned level operator** M⁰_a h(u) := (1/m)Σ_i h(ψ_i(u)) acts on functions of x↾a.

**Lemma 3.1 (decomposition).** Put W_{n+1} := {x ↦ h(x↾n)(−1)^{x_n}}. Then:
* L²(2^ω,λ) = ℂ·1 ⊕ ⨁_{n≥0} W_{n+1} (orthogonal; closure of the sum);
* the functions with E[f | x↾a] = 0 are exactly ⨁_{n≥a} W_{n+1};
* each W_{n+1} is invariant under every U_i f := f∘ψ_i, and on W_{n+1} the average M := (1/m)Σ_iU_i acts as M_n acts on h.

*Proof.* Martingale differences of the coordinate filtration give the decomposition. Causality gives f(ψ_i x) = h(ψ_i(x↾n))(−1)^{x_n ⊕ c_i(x↾n)}. ∎

**Lemma 3.2 (separation identity).** For a clopen set C and an involution ψ, put f := 2·1_C − 1. Then λ{x : 1_C(x) ≠ 1_C(ψx)} = ½(1 − ⟨f, f∘ψ⟩). More generally, let P be ψ-invariant and f := (2·1_C − 1)·1_P. Then λ{x ∈ P : C separates x and ψx} = ½(λ(P) − ⟨f, f∘ψ⟩).

*Proof.* (f(x) − f(ψx))² = 4·1{separated} on P, and E[(f − f∘ψ)²] = 2‖f‖² − 2⟨f, f∘ψ⟩ by measure preservation. ∎

**Theorem 3 (spectral barrier).** Suppose η > 0 and a ∈ ℕ satisfy ‖M_n‖_top := max spec(M_n) ≤ 1 − η for every n ≥ a.
(i) Every clopen C with E[1_C | x↾a] = ½ satisfies (1/m)Σ_i λ{x : C separates x, ψ_i x} ≥ η/2.
(ii) Let O ⊆ {0,1}^a be one orbit of the action of ⟨ψ₁,…,ψ_m⟩ on level a, and let P := ⋃_{u∈O}[u]. Let η₀ > 0 be the spectral gap of M⁰_a on functions on O orthogonal to 1_O (positive, since the orbit graph is finite and connected), and put η′ := min(η, η₀). Then every balanced split C of P satisfies

  (1/m)Σ_i λ{x ∈ P : C separates x and ψ_i x} ≥ (3/8)·η′·λ(P).

(iii) Consequently, let G_i ∈ F₂ be maps with fibres exactly {x, ψ_i x}, equipped with d ≡ 1. Then the family {(G_i, 1)} violates Definition 1.3 at the state P of (ii) for every ε < (9/28)η′.

*Proof.*
(i)
* f := 2·1_C − 1 lies in ⨁_{n≥a}W_{n+1} and ‖f‖² = 1. By Lemma 3.1, ⟨f, Mf⟩ ≤ 1 − η.
* Average Lemma 3.2 over i.

(ii)
* P is invariant under every ψ_i, and L²(P) splits into a low part (functions of x↾a supported on O) and a fresh part (⨁_{n≥a}W_{n+1} restricted to P). Both are M-invariant.
* Put f := (2·1_C − 1)1_P and write f = m₁·1_P + g with g ⊥ 1_P, where m₁ = 2α − 1 and α = λ(P∩C)/λ(P) ∈ [¼,¾].
* Then ⟨f, Mf⟩ = m₁²λ(P) + ⟨g, Mg⟩ ≤ m₁²λ(P) + (1−η′)‖g‖². Here ‖g‖² = (1−m₁²)λ(P) ≥ ¾λ(P).
* Lemma 3.2 gives (1/m)Σ_iλ{x∈P : sep_i} = ½(λ(P) − ⟨f,Mf⟩) ≥ ½η′‖g‖² ≥ (3/8)η′λ(P).

(iii)
* With d ≡ 1 the savings transform has B ≡ 0, so μ_i = 2λ.
* By fairness, μ_i(Sep_i(P,C)) = 2λ{x ∈ P : sep_i} and μ_i(Pair_i(P)) = 2λ(P).
* With unit weights, the left side of Definition 1.3 is at least (9/4)η′λ(P), and the right side is 7ελ(P). ∎

So a uniform spectral gap of the signed level operators is an exact, checkable obstruction to the (A′) mechanism. It holds for every balanced split, not only for parities or coordinates, at every orbit state above the gap level.

**Lemma 4 (no local frustration).** Let W be a finite set of causal fair homeomorphisms. For n ≥ 0 let F_W(n) be the set of v ∈ {0,1}^n for which some w ∈ W has w(v) = v and flips coordinate n on [v]. Then

  Σ_{n≥0} 2^{−n}|F_W(n)| ≤ |W|.

*Proof.*
* Fix w and let Fix_n := {v ∈ {0,1}^n : w(v) = v}. A vertex u ∈ {0,1}^{n+1} is fixed by w iff u↾n ∈ Fix_n and w does not flip coordinate n on [u↾n].
* Hence |Fix_{n+1}| = 2(|Fix_n| − |F_{{w}}(n)|), so m_n := 2^{−n}|Fix_n| satisfies m_{n+1} = m_n − 2^{−n}|F_{{w}}(n)|.
* So Σ_n 2^{−n}|F_{{w}}(n)| = m₀ − lim m_n ≤ 1. Sum over w ∈ W. ∎

**Corollary 4.1 (rigidity is never local).** Let ψ₁,…,ψ_m be causal involutions and L ∈ ℕ. A closed walk of length ≤ L at v in the level-n signed graph with odd sign product (a *frustrated cycle*) is a word w of length ≤ L with v ∈ F_{{w}}(n).
* By Lemma 4 applied to the finitely many words of length ≤ L, the fraction of level-n vertices lying on a frustrated cycle of length ≤ L is summable in n. In particular it tends to 0.
* So the standard local certificate for a signed spectral gap fails for every causal family. That certificate is "every vertex lies on a frustrated cycle of bounded length, hence Σ|h(x)−σh(y)|² ≥ (4/L)Σ|h|² up to bounded overlap".
* A uniform gap ‖M_n‖_top ≤ 1 − η, if it holds, must come from global expansion of the signed level graphs. ∎

## 5. Consequences

**Corollary 5.1 (the (A′) mechanism fails for the two-frame union, conditional on Conjecture R).** Assume Conjecture R with constants η, n₀. Let a ≥ n₀ and let O be any orbit of ⟨ψ₀,ψ₁,ψ′₀⟩ on {0,1}^a.
* The state P := ⋃_{u∈O}[u] admits no balanced split satisfying Definition 1.3 for the three-map family {(U₀,1), (U₁,1), (U′₀,1)} once ε < (9/28)·min(η, η₀(O)). This is Theorem 3(iii).
* Hence FD₂^{K_mix} ∪ FD₂^{K′_mix} is **not halving-dispersible**. Theorem 1, and with it every instance of the S087/S088/Theorem 1 mechanism, coordinates, parities or arbitrary nonlinear clopen splits, cannot by itself produce a survivor for this union.
* U₀, U₁ and U′₀ each delete one fixed coordinate after a computable fair homeomorphism, so they preserve CR on every input (THM-0038). The barrier therefore concerns the **mechanism**, not the existence of survivors. Every element of CR∖MLR survives these three maps.

**Proposition 5.2 (the invariance–neutralization dichotomy).** Let G ∈ F₂, let μ := (2+B_∞)λ, and let P₀ ⊇ P₁ ⊇ … be clopen states with P_{k+1} ∈ {P_k ∩ C_k, P_k ∖ C_k}.
(i) Pair(P_{k+1}) ⊆ Pair(P_k) ∖ Sep(P_k, C_k). Hence Σ_k μ(Sep(P_k,C_k)) ≤ μ(Pair(P₀)). The unnormalized capital-weighted mass a construction can ever spend on separating the pairs of one map is bounded: separated pairs never return.
(ii) The potential bookkeeping of Theorem 1 charges the **normalized** cost γ = λ(P_k)⁻¹μ(Sep), while λ(P_k) decreases geometrically. Take G with all fibres double and fixed partner ψ, and d ≡ 1. Then Ψ(P) = λ(P)⁻¹λ(P ∪ ψP) = 2 − π(P), where π(P) := λ(P ∩ ψ⁻¹P)/λ(P). The rule "keep the side with the smaller potential" therefore keeps the side with the **larger** normalized pair weight.
(iii) Under the hypothesis of Theorem 3(ii), every balanced split of an orbit state separates at least a (3/8)η′ fraction of its pairs. So along the potential-minimizing path the normalized cost stays bounded below as long as the normalized pair weight does.

*Proof.* (i) A pair separated by C_k has one point outside P_{k+1}, and P_{k+1} ⊆ P_k. Sum over k. (ii) For d ≡ 1, B ≡ 0, c^P(G(x)↾t) → 1_{P∪ψP}(x) as t → ∞, and fairness gives Ψ = λ(P)⁻¹λ(P∪ψP). Finally λ(P∪ψP) = 2λ(P) − λ(P∩ψP). (iii) is Theorem 3(ii). ∎

**Reading.** At a state with rigid dominant partner action, a balanced split either nearly preserves the pairs (invariance, impossible by Theorem 3) or separates a positive fraction of them (**neutralization**).
* For fixed-hold maps, neutralization is affordable in absolute terms (i). But the normalized accounting of Theorem 1 does not see that, and its selection rule works against draining (ii).
* For infinitely resolving self-reading observers, splitting the pair of the current hold is exactly the event S083 Lemma 3.4 and P4-S087 Theorem 8 read to resolve the hold.
* So a survivor for a rigid family of self-reading observers must neutralize **unreadably**. A Route-A family must make every neutralization readable. This is the sharpened frontier left by this session. It is an analysis, not a theorem.
