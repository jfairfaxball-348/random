## 2. Front A/E — a full affine finite-kernel splitting theorem (INTERNALLY PROVED)

Work in Cantor space X=(F_2)^N with coordinatewise XOR and Haar/fair measure lambda. Let L:X->X be a **total computable continuous GROUP HOMOMORPHISM**, surjective, with finite kernel K (size 2^d). A computable affine translate is F(x)=L(x) xor b with computable b. The assumption 'surjective' is automatic when L is fair: its compact image is closed, and a proper closed image omits a positive-measure output cylinder.

**Theorem A116-1 (computable finite-kernel splitting, beyond finite-state).** There exist d finite SOURCE coordinate indices i_1,...,i_d such that, putting A(x)=(x_(i_1),...,x_(i_d)), the map

    H(x)=(A(x),L(x)) : X -> (F_2)^d x X

is a total computable fair HOMEOMORPHISM with computable inverse, and L=Del_d composed H. Here Del_d discards the first d tag bits. In particular for EVERY integer k>=1,

    L(R_k) subset R_k  and  F(R_k) subset R_k.

For d=0, L itself is a fair computable homeomorphism; for d=1, one source coordinate detecting the unique nonzero kernel element is enough. No finite-state, bounded input-use or computable bound on the use excess is assumed.

**Proof.** Since K is a d-dimensional binary vector space and separates distinct points in coordinates, the coordinate restrictions on K span its d-dimensional dual: if their span were proper, some nonzero k in K would be annihilated by every source coordinate, contradiction. Choose d coordinate evaluations forming a basis of K*. Their joint A restricts to an isomorphism K->(F_2)^d. If H(x)=H(x'), then x xor x' is in K and A(x xor x')=0, hence x=x'. For any (a,y), choose x with L(x)=y by surjectivity; choose the unique t in K with A(t)=a xor A(x); then H(x xor t)=(a,y). Thus H is a continuous bijection from compact X to Hausdorff Cantor product and has continuous inverse.

For **effectivity** A is a fixed finite coordinate projection, hence computable. A total computable bijection of effectively compact Cantor space onto itself has computable inverse: for any requested finite source prefix, disjoint compact images of its finitely many source cylinders can be effectively separated by a finite target-prefix depth, found by an exhaustive search using the uniform computable modulus and finite-cylinder image exclusion. This gives the unique input prefix from the output oracle; no decidable kernel predicate or uniform extraction of i_j from L is claimed. Alternatively in d=1 explicitly solve on each clopen tag sheet by computable compact unique inversion.

For **fairness**, translation of source measure by each t in K leaves lambda invariant, fixes L and permutes A through all 2^d tags. Thus for any target cylinder [tau], the 2^d sets {x:L(x) in[tau], A(x)=a} have equal measure and partition L^-1[tau], whose measure is 2^-|tau|. Each has mass 2^(-d-|tau|); H pushes lambda to product fair measure. It is therefore a computable fair homeomorphism. S113's all-k tag deletion theorem and fair-homeomorphism invariance yield L(x)=Del_d(H(x)) in R_k whenever x in R_k. Finally translating by computable b is a computable fair homeomorphism, proving the affine claim. QED.

**Corollary A116-2 (linear F2 rigidity):** A globally fair computable affine map with every fibre <=2 either has trivial kernel and is a fair computable homeomorphism, or has one nonzero kernel element g and is EVERYWHERE EXACTLY TWO, with F^-1(y)={x,x xor g} for every y and every chosen x in that fibre. ## 3. Infinite-memory algebraic stress test of A116-1

Define the computable permutation q of zero-based coordinates by swapping 4^j and 2*4^j for every j>=0, fixing all others (including 0). These pairs are disjoint, and q=q^-1. Set

    L_q(x)_n = x_(q(n)) xor x_(q(n+1))  (n>=0).

For every infinite y and choice a=x_(q(0))=x_0, the recursion x_(q(n+1))=a xor y_0 xor ... xor y_n determines all x coordinates. There are precisely TWO actual infinite inverse streams, differing at EVERY coordinate (global complement), no hidden limit paths; every y is hit. H_q(x)=(x_0,L_q(x)) is a computable linear fair homeomorphism by explicit recursion. Hence every cylinder of output length m has fair mass 2^-m; independent finite enumeration agrees. For m=4^j+1 the coordinate L_q(x)_(m-1) needs input bit index 2*4^j; no input modulus m+c for FIXED c can compute that prefix across all j. This is a genuine unbounded-use nonfinite-state affine EXACT TWO map, not merely another additive-one transducer. Its D_r=X for every r>=1, and it preserves R_k for all finite k. Thus unbounded use, infinite memory and an actual paired fibre still fail as a CR-destruction mechanism without nonlinearity.

## 4. Front B — a source-conditioned result not requiring computable stratum masses

**Theorem B116-1 (exact finite posterior granularity).** Let G:X->X be total computable FAIR, with a supplied UNIFORM use bound u(m)<=m+c for some fixed integer c>=0. No linearity or F2 condition is needed. For every output word tau of length m, exactly 2^c distinct source words of length m+c map into [tau]. For any source word s of length r<=m+c the finite conditional price

    P_m(s | tau) = lambda([s] intersect G^-1[tau]) / lambda(G^-1[tau])

is a uniformly computable integer multiple of 2^-c. In particular if x is an ACTUAL inverse of y, then for ALL m with m+c>=r,

    P_m(x|r | y|m) >= 2^-c.

Proof: use bound makes each length-(m+c) input cylinder map entirely into a unique output m-cylinder. Such source cylinders each have mass 2^-(m+c); fairness forces exactly 2^c of them above each length-m target, and counting those extending s proves the formula. The cylinder containing the actual x is one such candidate, so the lower bound holds at EVERY depth, even at atypical y. QED.

This is NOT a disintegration or a computable coherent output-to-source martingale. The posterior for a fixed r-source prefix may fluctuate among discrete values with m, and its limit at arbitrary y is not promised. Bounded c gives nonvanishing FINITE posterior weight at every actual source; it therefore rules out S004-style vanishing sheet weight as a mechanism in this subfamily, but alone does NOT settle any c>=2 CR preservation. In fact S112's exact-two **additive-one** halting-coded G_T has noncomputable lambda(D_1), demonstrating that rational granular posteriors do NOT compute the mass of the infinite-lifetime stratum. S108's positive-measure nowhere-dense boundary is another legal additive-one case. S109's additive-one martingale compiler remains a separate theorem, not a consequence of this price floor. First unsupported inference: from finitely many exact rational posterior prices with a floor to ONE total computable rational martingale transferring EVERY unbounded output win to the selected actual CR source in general c=2.

**B116-2 (eventual support without effective last stage):** For a fixed y and fixed source prefix s, the assertion [s] intersects G^-1[y|m] is monotone in m; its persistence for all m is equivalent by compactness to existence of an ACTUAL inverse in [s]. This is a compactness check, not a new infinite-fibre theorem.

## 5. Front C — measure-free selection obstruction beyond the affine case
