## Mathematical validation

### 1. Faithful moving-reservation scan

The Definition-1 protocol keeps the current sentinel unread until its own A/B event. Prospective future blocks are only transient.

On a no-event continuation each active reservation is consumed after finite interaction and the background sweep eventually consumes every other coordinate. Hence only the current sentinel remains permanently unread.

On an A/B event the current sentinel is consumed and the active reservation is frozen only temporarily until it becomes the next target.

**Status: VALID.**

### 2. Ambient set / reservation stream / selected subsequence

The three objects are genuinely distinct.

The ambient \(A_i\) set is a semantic property of raw blocks on the source. A reservation stream is generated by one scan epoch. The next target is the member active when the positive certificate appears.

Because the scan state and certificate time can depend on already exposed source values, the selected target sequence need not be computable independently of the source.

**Status: VALID.**

### 3. Selector thickness theorem

If a faithful selector completes infinitely many epochs and selects Case A infinitely often, the P4-S043 asynchronous wager applies directly: each A certificate certifies the current raw sentinel bit, B epochs have zero stake, and there is no C trap.

The scan is globally one-hole by item 1. Hence a computable output martingale succeeds and \(X\notin OH\).

The contrapositive is used only as a necessary condition under a hypothetical \(X\in OH\).

**Status: VALID.**

### 4. Concrete thickness hypotheses

A C-free computable lane on which A is cofinite is sufficient because all target blocks remain A/B and eventually all are A.

The C-free qualification is essential: one early C exception can absorb a faithful selector.

Finite possible-index coverage plus certificate-time domination is sufficient when every possible selected candidate is C-free and infinitely many epochs have all possible candidates in A.

Bounded gaps and positive density are not enough: an event clock may consistently select complementary reservation indices.

Finite-union lane concentration is not enough without controlling which lane is active at certificate time.

A hypothesis only about computable subsequences does not automatically apply because the actual event-selected sequence has not been proved computable without \(X\).

**Status: VALID.**

### 9. Why this does not diagonalize against all computable selectors

The construction is not claimed to enumerate exactly all total selector programs. That set has no effective total-only enumeration suitable for the sequential construction.

More decisively, after a computable-target model is built, Case-A pairs are c.e. because the target values are computable and A has a finite positive witness.

If infinitely many blocks have A, one can enumerate increasing certified A pairs.

The admissibility subtlety is handled correctly in the repaired proof: the exact target A-certificate time is computable on the structural target, so the next certified block is held only for a known finite window. If the expected event fails on an off-target transcript, that reservation is consumed and the ordinary transient-reservation sweep resumes. Thus the resulting post-construction scan remains globally one-hole.

On the structural target, every expected certificate appears in its finite window and the scan targets A forever.
