## C. NEW theorem: recovering an exact pair is strictly harder than recovering one

Fix the S120/S121 globally fair ADDITIVE-ONE EXACT-TWO release-and-erase map (G_U) for a c.e.-open set (U\subseteq X). Output oracle (y) is read by a randomised algorithm using independent fair random coins. If (y\notin U), the complete fibre is ({0y,1y}). If the first trigger is at (t), so (y=\rho c v) with (|\rho|=t), its complete fibre is ({c\rho0v,c\rho1v}). A trigger depends only on (\rho), before the release bit c, so BOTH c=0 and c=1 are available at arbitrary sufficiently late local trigger extensions.

Define **exact-pair success** as emitting TWO COMPLETE **DISTINCT** streams whose unordered set equals the **ENTIRE** true fibre. Any divergence, duplicate streams or merely-one-valid candidate counts as failure. Define the uniform worst-case lower success guarantee (r(A)=\inf_{y\in\mathrm{CR}}\mathbb P(A^y\text{ exactly recovers both})). Suppose there is a CR boundary point (y_*\in(X\setminus U)\cap\overline U). (The hypothesis holds for S121's dense fat K, including its class with no computable supported measure, and for S125's nondense example (U=0V) with (y_*=0w).)

**Theorem C126-1 (INTERNALLY PROVED, sharp).** Among randomized oracle procedures almost surely producing BOTH complete candidate streams on every CR output, (sup_A r(A)=\boxed{1/3}). Among arbitrary PARTIAL randomized procedures with NONTERMINATION counted as failure, (sup_A r(A)=\boxed{1/2}).

**Upper bound for almost-surely-total pairs, without assuming oracle selection.** At (y_*) the actual pair begins with 0 and 1. Since both candidate streams are a.s. complete, for each (epsilon>0) there is a finite oracle-prefix/finite coin-time event E of probability (e\ge1-\epsilon) on which the FIRST input bit of BOTH output candidates is already irrevocably written. The event and written bits are unchanged on every oracle continuation of that prefix. Partition E into mass (p) with distinct first bits, (q_0) with 00 and (q_1) with 11, so (e=p+q_0+q_1). At (y_*), success (le p+1-e\le p+\epsilon). Select (c\in\{0,1\}) with (q_c\le(e-p)/2), take a first-trigger cylinder inside U extending the fixed prefix of (y_*), choose released bit c and then ANY CR continuation (z) inside this positive cylinder. Every true inverse over z begins with c. On E, success requires BOTH initially written bits to equal c; hence (mathrm{success}(z)\le q_c+1-e\le(1-p)/2+\epsilon/2). Consequently
[
r(A)\le\min\{p+\epsilon,(1-p)/2+\epsilon/2\}\le 1/3+\epsilon,
]
since the first two lines intersect at p approximately 1/3. Let (epsilon\downarrow0). The three early patterns {01/10,00,11} are mutually exclusive, so the bound does not rely on independence of candidate decisions.

**Achievability, explicitly TOTAL a.s.** Define uniformly computable total candidate streams (C_{a,b}(y)): emit initial key a; copy the observed output bits until the first release; then insert arbitrary erased bit b instead of the released output key c, and copy the remaining output tail. On no release this is simply a y, independently of b. Choose one of the following THREE ordered pairs with equal probability (1/3), by rejection sampling of fair coin pairs (00,01,10 accepted, 11 retried):
[
(C_{0,0},C_{1,0}),\quad(C_{0,0},C_{0,1}),\quad(C_{1,0},C_{1,1}).
]
On K, only the first pair lists the distinct correct keys; on U with released c=0 only the second lists the two differing erased bits; on U with c=1 only the third does. Therefore every CR output has EXACT success 1/3. Rejection sampling terminates with probability one, and each candidate stream is total for all infinite oracles.

**Upper bound for unrestricted PARTIAL pairs.** Let (p) be the probability at (y_*) that an algorithm EVER outputs BOTH first bits and they are DISTINCT. Exact success on (y_*) is at most p. For any (epsilon>0), choose a finite-time, finite-use event E consisting of those irrevocable distinct first-bit outputs, mass (\ge p-\epsilon). Any later triggered CR continuation extending the same prefix, with either released key, has TWO actual inverses whose first bits are IDENTICAL; all E runs fail irrevocably, so (mathrm{success}(z)\le1-p+\epsilon).
