## B169.1 — Every fresh-query adaptive scan is an EFFECTIVE UNIFORM limit of fair homeomorphisms

Let q(t,τ), for |τ|=t, be any total computable query rule with q(t,τ) distinct from all earlier q(s,τ↾s), s<t. Let F_q(x)(t)=x(q(t,F_q(x)↾t)). This is S168's general fresh-query scan; each prefix has t distinct independent queried source bits and λ(F_q⁻¹[τ])=2⁻|τ|.

For each N∈N, define q_N by following q for stages t<N, and, at EVERY t≥N regardless of future output transcript, query the LEAST nonnegative source coordinate not previously queried on that transcript. Let F_N be its scan.

**Theorem B169.1.** For every q as above, uniformly in an index of q and N: (i) F_N is a TOTAL computable globally fair Cantor homeomorphism, with exactly ONE complete inverse above EVERY y; (ii) for every x, F_N(x)↾N=F_q(x)↾N; thus F_N→F_q EFFECTIVELY UNIFORMLY, in the Cantor prefix metric, with output precision N at stage N.

**Proof.** Both query protocols are uniformly total recursive and select a fresh coordinate per finite transcript: while t<N this is a hypothesis on q; from t=N it is an explicit least-unused rule. Given arbitrary y, the transcript determines each query, and these constraints fix exactly one input coordinate per stage. After N, taking least unused in order exhausts all coordinates: for any fixed coordinate j, either j was already queried in the first N stages or its finite rank among the remaining naturals is eventually reached. Hence all source coordinates are queried on EVERY y, leaving exactly one complete inverse, by B168.1. The inverse x_y can be computed from y: to compute x_y(j), simulate the transcript and queries until coordinate j is visited (finite on every y). Forward total computability follows from total finite-stage queries and finite prefix use; compactness also supplies effective uniform source use at each output precision. On each length-m output transcript the m query coordinates are pairwise distinct, so the source cylinder event has probability 2⁻m; therefore λ is preserved for ALL cylinders (including paths causing very long q computation). Agreement of q_N and q on stages <N is by induction on common transcript, for EVERY x. For Cantor distance d(a,b)≤2⁻N whenever their first N output bits agree, the bound is computable and uniform in x. QED, INTERNAL.

**Corollary B169.2 (preservation NOT closed under effective uniform limits).** Use the EXISTING S011 wtt-autoreducible CR witness Y, S011 q and rational d: its F=F_q belongs to F2, but d succeeds on F(Y), so F(Y)∉CR. Apply Theorem B169.1: each F_N belongs to F1, hence F_N(Y)∈CR by the already established S001/E-ISO conservation; nevertheless F_N→F effectively uniformly, and the limit F does NOT preserve CR. The SAME Y is used for EVERY N and the limit. No new witness theorem is claimed beyond S011 and this approximation. This counterexample disproves proposed transfer rules based ONLY on effective uniform convergence and F1-preservation; it does not disprove a transfer with additional effective capital/sibling conditions. QED, INTERNAL.

**Quantifier trap.** We have ∀m ∃N=m ∀x: F_N(x)↾m=F(x)↾m. We do NOT have ∃fixed N∀m: F_N(x)↾m=F(x)↾m on S011's target. Every d-success prefix of F(Y) is matched by some F_N(Y), but these N may grow and there is NO fixed N on whose image d succeeds. Finite-stage closeness is not a witness of finite-k detection.

## C169 — S168 exceptional continuum is also an effective-uniform degree explosion

Take the S168 T: emit source coordinates 2t while no emitted 1 has been seen; after the first 1, query least unused coordinates forever. T is total, fair, CR-preserving; all y≠0^ω have singleton complete fibres, but T⁻¹(0^ω) consists of all sources with even coordinates zero, hence has cardinality continuum.

Apply B169.1. Each T_N has degree EXACTLY ONE on EVERY infinite y and globally fair, with T_N(x)↾N=T(x)↾N for ALL x. Yet their effective uniform limit has continuum many inverse streams over the exceptional 0^ω. Thus even F1 (and therefore no fixed F_k) is NOT closed under effective uniform limit among fair total computable maps. This is a universal-all-output inverse statement, not a finite-prefix counting inference. For T itself every CR input produces a nonzero output so T is NOT a separator (S168).

## D169 — Subclass H1 progress from the S011/S012 predicate; boundary of ML-test compilation

**Derived scoped positive theorem (S011/S012 mechanism, not novel):** Suppose x is computably random and has a partial oracle algorithm M such that for EVERY natural j, its computation M^x(j) halts, returns x(j), and never queries source coordinate j. Then the S011 least-fresh sentinel scan, applied to M, yields a total computable globally fair F∈F2 and an exact rational output martingale that doubles at every target-success sentinel and therefore succeeds on F(x). Its proof uses only target-halting/self-avoidance, not a uniform wtt use bound: nonhalting siblings produce a persistent single sentinel hole and two inverses; all-trigger siblings exhaust all coordinates, giving one inverse. Thus any SUCH computably random source is outside R2 and, by MLR⊆R2, outside MLR. This does NOT establish that every CR\MLR source satisfies the hypothesis. See S011, S012 for inherited proof, not a new attribution.

The tempting universal-completion move is to replace an arbitrary universal ML-test witness by this predictor. It fails at a precise premise: U_n membership gives no unqueried target-bit value before the target coordinate is read, whereas M^x(j) must compute it from OTHER coordinates. Imposing a uniform effective horizon on all siblings collapses the least-fresh scheme to a computable homeomorphism by S013, which preserves CR. Letting the horizon diverge is exactly the B169 uniform-limit trap. A bounded reserve of F_N approximations therefore supplies NO H1 witness without a global ALL-OUTPUT fibre-and-stake proof.
