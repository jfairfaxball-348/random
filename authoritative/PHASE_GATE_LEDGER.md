# Phase Gate Ledger

| Gate | Status | Meaning |
|---|---|---|
| Scaffold -> Phase 1 | CLOSED | Await explicit owner authorization to begin research/catalogue work. |
| Phase 1 -> Phase 2 | CLOSED | No Phase-1 work has occurred. |
| Phase 2 -> Phase 3 | CLOSED | No Phase-2 work has occurred. |
| Phase 3 -> Phase 4 | CLOSED | No Phase-3 work has occurred. |
| Phase 4 -> Phase 5 | CLOSED | No Phase-4 work has occurred. |
| Phase 5 completion | CLOSED | No publication work has occurred. |

Gate statuses: `CLOSED`, `UNDER_REVIEW`, `PASS`, `FAIL`, `BACKTRACK`.

A PASS must link to a completed gate review using `templates/gate-review.md`. A gate review must state evidence, unresolved risks and exact next authorization.
