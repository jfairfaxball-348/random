## Residual gap register

P1-S013 uses four classes.

1. **Gate-critical gap:** prevents an honest readiness finding because a consequential catalogue claim or Gate-1 deliverable lacks adequate support.
2. **Nonblocking provenance improvement:** better original-source access would strengthen historical or formulation provenance, but current discovery-relevant statements are adequately sourced or carefully qualified.
3. **Deliberately bounded omission:** a topic is intentionally not surveyed beyond the depth needed to orient discovery.
4. **Historical/navigation gap replaced:** the original historical source remains uninspected, but exact current syntax is grounded in later statement-inspected primary literature; the older source is retained for provenance/navigation only.
