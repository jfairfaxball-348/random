# Agent Search Guide

Phase 1 is designed to minimize repeated reading and terminology drift.

## Stable IDs

Use prefixes:
- `SRC-####` source
- `DEF-####` definition/notion
- `THM-####` theorem/characterization
- `REL-####` implication/equivalence/separation relation
- `QST-####` open/status question
- `AUT-####` author/researcher record
- `CAND-##` discovery candidate
- `PA-####` prior-art finding
- `CLM-####` programme claim

IDs are permanent. Retired records remain addressable.

## Retrieval strategy

Agents should search structured indexes first, then follow IDs to detailed notes. Avoid using one giant narrative literature review as the only knowledge store.

Recommended Phase-1 indexes:
- sources by topic/author/year;
- definitions and aliases;
- theorem characterizations;
- implication/equivalence graph;
- open/status questions;
- author/topic matrix;
- search-log/query vocabulary;
- unresolved terminology/access gaps.

## Record style

Put exact scope near the top. Include aliases and search terms. Cross-link related IDs. Keep source-derived fact separate from programme interpretation. Add dates to status-sensitive claims.
