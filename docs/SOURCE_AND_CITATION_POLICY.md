# Source and Citation Policy

## Source hierarchy

For exact mathematical definitions, theorem scope and priority, prefer:
1. original peer-reviewed paper or authoritative preprint;
2. later primary paper explicitly restating the result;
3. scholarly monograph/survey;
4. reputable secondary exposition.

Secondary sources can guide discovery but do not alone settle priority when primary evidence is obtainable.

## Access levels

Each source record carries one of:
- `METADATA_ONLY`
- `ABSTRACT_INSPECTED`
- `STATEMENT_INSPECTED`
- `PROOF_INSPECTED`
- `SECONDARY_ONLY`
- `UNAVAILABLE`

Never imply a proof was checked when only an abstract was seen.

## Storage

Do not copy whole copyrighted papers into the repository merely to create a local library. Store metadata, DOI/arXiv/stable URLs, original summaries, exact short quotations only when justified, theorem pointers, page/section locators where known and derived cross-links.

## Priority/novelty language

Use calibrated phrases such as:
- "located prior art";
- "no matching result found in the documented search";
- "current status unresolved";
- "candidate appears distinct under the inspected sources".

Do not write "open", "new", "first", or "novel" as an established fact without evidence appropriate to that claim.
