# Fairfax-Ball Randomness Research Programme

This repository is the authoritative research record for a five-phase programme whose long-term goal is to determine whether there is a mathematically natural, genuinely novel and publishable notion worthy of the name **Fairfax-Ball Randomness**, and, only if earned by the mathematics, to define it rigorously and place it in the public mathematical record.

P1-S001 through P1-S003 are completed. Phase 1 remains incomplete and Gate 1 is CLOSED / NOT READY FOR REVIEW. Phases 2–5 remain CLOSED; no candidate selection, novelty gate, original mathematics, formalisation or publication work is authorized.

## Five gated phases

1. **Research / Catalogue** — build an extensive, source-grounded, agent-searchable map of algorithmic randomness and adjacent foundations. External papers need not be stored; catalogue metadata, exact theorem scope, links, notes and derived research records are stored.
2. **Discovery** — use the Phase-1 library to identify open questions, structural gaps and a bounded portfolio of serious candidate contributions.
3. **Novelty / Prior Art** — stress-test candidates for prior discovery, mathematical interest, usefulness, beneficiaries and publication relevance. No candidate enters mathematics without passing this gate.
4. **Mathematics** — perform the proof/disproof work on the selected target. Formalisation in Lean and Palomar registration may be included when appropriate, but do not confuse formal verification with novelty or significance.
5. **Publication** — prepare an arXiv preprint and pursue an appropriate peer-reviewed journal publication, with accurate disclosure, source checking and external-review discipline.

A phase transition is permitted only when the current phase's committed gate record is marked **PASS** and the authoritative state explicitly opens the next phase.

## Long-term objective

The name **Fairfax-Ball Randomness** is an objective of the programme, not a presupposed result. The programme must be willing to conclude that a proposed notion is already known, equivalent to an existing notion, mathematically uninteresting, inadequately motivated, or otherwise not publication-worthy. The name is earned only by a definition and theorem package that survive the preceding gates.
